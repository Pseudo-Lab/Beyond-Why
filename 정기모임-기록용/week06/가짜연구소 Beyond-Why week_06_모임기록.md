## 1️⃣ 차원의 저주와 회귀 분석

### 차원의 저주(Curse of Dimensionality) 문제

**정의**
- 특성 X의 개수가 많아지면 보정 공식을 적용할 때 데이터 양이 급증하는 문제
- 모든 X의 조합을 고려할 때 특히 두드러짐
- 평균 계산 과정에서 각 셀(cell)의 데이터 개수가 부족해지는 현상 발생

**문제점**
```
예시: 3개 변수, 각 10개 수준
→ 10 × 10 × 10 = 1,000개 조합
→ 각 조합별로 충분한 샘플 필요

5개 변수, 각 10개 수준
→ 10^5 = 100,000개 조합
→ 데이터가 기하급수적으로 필요
```

### 회귀 분석을 통한 완화

**핵심 아이디어**
- 특정 **함수 형태를 가정**하고 예측 값을 활용
- 모든 X 조합별 평균 계산 대신 함수를 가정하고 피팅하여 문제 해결

**방법**
```
기존 방식 (차원의 저주 발생):
각 (X₁, X₂, ..., Xₙ) 조합별로 평균 계산
→ 데이터 부족 문제

회귀 분석 방식 (차원의 저주 완화):
Y = β₀ + β₁T + β₂X₁ + β₃X₂ + ... + ε
→ 함수 형태로 전체 관계 모델링
→ 관측되지 않은 조합에 대해서도 예측 가능
```

### 인과 추정에서의 활용

**카운터팩추얼(Counterfactual) 샘플 문제 해결**
- 회귀 분석을 이용하면 X와 T가 주어진 경우 Y를 예측 가능
- **실제로 처치 받은 집단이 없더라도** Y 값을 추정하여 인과 추정량을 구할 수 있음
- 이 방법으로 차원의 저주가 완화됨

### Overfitting과 Regularization 고려사항

**주의점**
- 모델 피팅을 통해 오버피팅이 이론적으로 완화되지만 **피팅 정도가 중요**
- 오버피팅만 추구하다가 언더피팅으로 전환되는 현상 주의
- 검증 차원에서 모든 데이터에 맞추려면 기본 모델 접근 필요

## 2️⃣ FWL 정리와 편향 제거 기법

### FWL(Frisch-Waugh-Lovell) 정리란?

**목적**
- 비실험 데이터에서 교란 요인으로 설명 가능한 부분을 제외
- **순수 처치 효과**를 추출하여 편향되지 않은 추정값 획득
- 다중 회귀 분석의 대안으로 3단계 잔차 회귀 방식 사용

### FWL 3단계 프로세스

**그래프 구조**
```
교란 변수(X)
  ↓  ↘
처치(T) → 결과(Y)
```

#### **1단계: 편향 제거 (Debiasing)** ⭐ 가장 중요!
```
T를 X에 회귀 → T의 잔차(T̃) 구하기

T̃ = T - Ê[T|X]
```
- 교란 요인 X로 설명되는 부분을 제거
- X와 무관한 순수한 처치 변동만 추출

#### **2단계: 잡음 제거 (Denoising)** - 선택사항
```
Y를 X에 회귀 → Y의 잔차(Ỹ) 구하기

Ỹ = Y - Ê[Y|X]
```
- 결과 변수에서도 교란 요인의 영향 제거
- **분산을 줄이는 역할** (추정값 자체는 변경 안 됨)
- 필수적이지 않지만 수행하면 유익

#### **3단계: 결과 모델**
```
Ỹ를 T̃에 회귀 → 인과 효과 β 추정

Ỹ = β × T̃ + ε
```
- 두 잔차 간 회귀를 통해 진짜 인과 효과 추정
- 다중 회귀와 동일한 결과

### 실무 예시: 매출-광고비-계절성

**상황 설정**
- Y (결과): 매출
- T (처치): 광고비
- X (교란 요인): 계절성

**문제점**
```
여름철:
- 기온 상승 → 광고비 증가 (음료 광고 등)
- 기온 상승 → 매출 증가 (음료 판매 자체 증가)

→ 광고비와 매출의 상관관계가 인과관계인지 불분명!
```

**FWL 적용**

**1단계: 광고비에서 계절성 제거**
```
광고비(T) = β₀ + β₁ × 계절(X) + 잔차(T̃)

T̃ = 계절과 무관한 순수 광고비 변동
```
- 여름철 자연스러운 광고비 증가분 제거
- 계절 효과를 제외한 순수한 광고비 변동만 추출

**2단계: 매출에서 계절성 제거**
```
매출(Y) = β₀ + β₁ × 계절(X) + 잔차(Ỹ)

Ỹ = 계절과 무관한 순수 매출 변동
```
- 여름철 자연스러운 매출 증가분 제거
- 광고비와 상관없이 계절이 매출에 미치는 영향 제거

**3단계: 순수 효과 측정**
```
Ỹ = β × T̃ + ε

β = 계절 효과를 제외한 광고비의 순수한 매출 효과
```

### 단계별 중요도

| 단계 | 역할 | 중요도 |
|------|------|--------|
| 1단계 | 편향 제거 | ⭐⭐⭐ 필수 |
| 2단계 | 잡음 제거 (분산 감소) | ⭐⭐ 권장 |
| 3단계 | 인과 효과 추정 | ⭐⭐⭐ 필수 |

## 3️⃣ 통제 변수와 분산 감소

### 잡음 제거 단계의 실무적 효용

**핵심 개념**
- 2단계(잡음 제거)는 **인과 추정값 자체를 변경하지 않음**
- 대신 **분산(variance)만 줄임**
- 추정값은 동일하지만 신뢰구간이 좁아짐

### 통제 변수 추가의 효과

**적절한 통제 변수 추가 시**
```
✅ 회귀 모델의 설명력 향상
✅ 예측 정확도 증가
✅ 잔차 분산 감소
✅ 신뢰구간 축소
✅ p-value 개선
```

**주의사항**
```
❌ 불필요한 변수 추가는 피해야 함
❌ Collider 변수는 절대 포함 금지
✅ 적절한 교란 변수만 선택
```

### 분산 감소의 원리

**회귀 모델의 변동 분해**
```
총 변동 = 설명 가능한 변동 + 설명 불가능한 변동 (잔차)

통제 변수 추가 전:
Var(Y) = Var(설명) + Var(잔차)

통제 변수 추가 후:
Var(Y) = Var(설명)↑ + Var(잔차)↓
```

**단계별 효과**
1. 통제 변수는 독립 변수로 **교란 요인을 설명**
2. 통제 변수 추가 → 교란 요인으로 설명 가능한 부분 증가
3. 결과 변수의 잔차 = 교란 요인으로 설명되지 않는 순수한 결과 변동
4. **결과의 분산 자체가 줄어듦**

### 실무적 이점

**1. 통계적 유의성 향상**
```
신뢰구간 축소:
[β - 1.96×SE, β + 1.96×SE]

SE↓ → 신뢰구간 좁아짐
     → p-value 개선
     → 더 설득력 있는 결과
```

**2. 리소스 절약**
- 모델 복잡도 증가로 추정의 분산 감소
- 추정값은 동일하지만 신뢰도 향상
- 더 적은 샘플로도 유의미한 결과 도출 가능

**3. 의사결정 지원**
- 신뢰구간이 좁아져 더 명확한 의사결정 가능
- 불확실성 감소
- 이해관계자 설득력 향상

## 4️⃣ 실무에서의 회귀 분석 활용

### 참가자들의 실무 경험

#### 경험 1: 회귀 분석의 설명력
- 여러 변수가 목표 변수에 미치는 영향을 분석할 때 회귀 모델이 유용
- **고성능 머신러닝 모델**은 성능은 우수하지만 변수 중요도를 설명하기 어려움
- **회귀 모델**은 의사결정권자나 이해관계자에게 설명하기 쉬움
- 실무적으로 적합한 선택

#### 경험 2: 표준화 계수 활용
- 회귀 모형의 회귀 계수 값을 **표준화**하여 사용
- 변수 간 상대적 중요도 비교 가능
- 단위가 다른 변수들을 동일 선상에서 비교

#### 경험 3: 학습 중
- 회귀 분석을 통해 경향을 보고한 적은 아직 없음
- 이번 스터디를 통해 공부하며 **활용해볼 계획**
- 이전에는 이해 부족으로 제대로 활용하지 못함

### 활용 전략

**언제 회귀 분석을 사용하는가?**
```
✅ 인과관계를 명확히 해야 할 때
✅ 이해관계자에게 설명이 필요할 때
✅ 여러 변수의 독립적 효과를 파악해야 할 때
✅ 차원의 저주 문제가 있을 때
✅ 카운터팩추얼 추정이 필요할 때
```

**언제 다른 방법을 고려하는가?**
```
⚠️ 비선형 관계가 강할 때 → 비선형 회귀, 머신러닝
⚠️ 예측 성능이 최우선일 때 → 앙상블, 딥러닝
⚠️ 교호작용이 복잡할 때 → 트리 기반 모델
```
