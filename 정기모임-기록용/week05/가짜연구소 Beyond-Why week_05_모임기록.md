## 💡 주요 토론 내용

## 1️⃣ 비순환 구조의 필요성

### 핵심 개념
- **인과 그래프**: X 변수에서 Y 변수로 가는 인과 과정을 시각화
- **불변성 유지**: X와 Y의 인과적 방향성을 일관되게 유지해야 함
- **순환 구조의 문제점**: Y에서 X로 되돌아가면 인과관계가 아닌 단순 상관관계로 전락

### 왜 방향 그래프인가?
- 인과성은 **방향적 특성**을 가지므로 방향 그래프(Directed Graph) 형태로 표현
- 양방향 영향 관계에서는 인과성을 논의할 수 없음

### 해결 방법
- **시간 차원 도입**: 변수를 시간에 따라 나누어 순환 구조를 해결
- **특정 경로 정의**: 사이클이 있는 경우, 전체가 아닌 특정 방향의 경로만 정의하여 이해

## 2️⃣ 식별 (Identification)

### 정의
- **뒷문 경로(Backdoor Path)**를 찾아 제거하는 과정
- Y가 X로 되돌아오거나 Confounder, Collider가 개입된 경우를 처리
- 올바른 인과 그래프를 그리기 위한 핵심 과정

### 편향의 종류

#### 📌 교란 편향 (Confounding Bias)
**개념**
- 원인(X)과 결과(Y)에 **모두 영향을 미치는 제3의 변수**
- 이를 배제하거나 통제하지 않으면 X와 Y에 양방향 영향을 주어 그래프가 복잡해짐

**구조**
- **Confounder**: X와 Y의 공통 원인 (Fork Structure)
- **분기 구조**에서 가짜 상관관계 발생

**대표 사례: 아이스크림과 익사 사고**
```
기온 ↗ → 아이스크림 구매 ↑
    ↘ → 익사 사고 ↑
```
- 기온이 상승하면 아이스크림 구매량과 익사 사고가 동시에 증가
- 기온이 **교란 변수**로 작용
- 기온을 고려하지 않으면 "아이스크림이 익사를 유발한다"는 오해 발생

**교란 변수 통제 방법**

1. **직접 통제**: 방정식에서 해당 변수를 직접 포함
   ```
   Y = β₀ + β₁X + β₂(기온) + ε
   ```

2. **변수 제외**: 방정식에서 아예 제외

3. **프록시 변수 사용**: 교란 변수를 설명하는 대리 변수 활용
   - 예: "지능" → IQ, 시험 성적 등으로 대체
   - 예: "관리자 자질" → 근속 기간, 교육 수준 등으로 대체

4. **무작위 배정 (Randomization)**: RCT를 통해 통제
   - 예: 하와이처럼 기온 차이가 적은 지역만 샘플링

**프록시 변수의 한계**
- 원래 교란 변수를 완전히 설명하거나 반영할 수 없음
- 정의가 잘 되어 있거나 도메인 합의가 있는 것을 사용해야 함
- 나이브하게 그래프나 회귀식에 넣는 것은 위험

**실무 사례: 지능**
- 모델링에서 모든 요소에 영향을 미치는 가장 큰 교란 변수
- 모호한 개념으로 X와 Y 모두에 영향을 주지만 정의 자체가 어려움
- 통제할 수 없어 설명에서 제외하기 힘듦

#### 📌 선택 편향 (Selection Bias)

**개념**
- **Collider**(충돌 변수)나 Mediator가 충분히 구분되지 않아 X와 Y 사이에 잘못된 상관성이나 인과성이 관찰되는 현상
- Collider: X와 Y의 **공통 결과**

**발생 원리**
- Collider 구조에서 **특정 집단만 분석**할 때 인위적인 연관성이 생김
- Collider 변수의 일부만 관찰할 경우, T와 Y 사이에 잘못된 상관성(양 또는 음)이 관찰됨

**선택 편향의 문제점**
- RCT(무작위 배정)로도 해결되지 않음
- 직관적이지 않아 잘못된 인과 추론을 유발

**회귀분석에서 피해야 할 실수**
1. ❌ Collider 변수나 자손 변수를 회귀분석에 포함시키면 안 됨
2. ❌ 분석 대상을 일부 필터링하여 특정 조건으로 제한해서는 안 됨
3. ❌ Collider 변수의 일부(예: 성별에서 남성만)만 선택하여 분석에 포함시키면 선택 편향 발생

**대처 방법**
- 표본 선정 과정에서 선택 편향을 유발할 수 있음을 **인식**
- 선택 편향을 회피하기 위한 전략 수립
- **충돌량 차이 통제 금지 원칙**

**실무 사례: 인바디 빅데이터의 선택 편향**
```
문제점:
- 인바디를 여러 번 측정하는 사람들은 주로 운동을 열심히 하는 사람들
- 빅데이터의 평균 근육량이 대한민국 평균보다 훨씬 높음
- 데이터 양이 많다고 해서 이를 모집단으로 가정하고 표준 기준으로 사용하는 것은 잘못됨

해결책:
- 측정하지 않은 사람들의 데이터를 다른 데이터셋에서 빌려오거나
- 인터폴레이션(interpolation)으로 추정하여 전체 집단에 포함
```

**실무 사례: 에듀윌 광고의 함정**
- "열 명 중 아홉 명 합격" 사례
- ❌ 합격자만 조사하면 편향된 결과
- ✅ 합격하지 못한 사람이나 강의 중간에 포기한 사람 등 다양한 사례를 포함해야 함

## 3️⃣ 경로 열림/닫힘 개념

### 핵심 개념
- 경로 열림/닫힘을 통해 **통계적 의존성** 판단
- 변수 통제 방법에 관한 내용
- Confounding variable, Collider 등의 통제 방법

### 분기 구조 (Fork Structure)
- 공통 원인을 통제하지 않아 **가짜 상관관계** 발생
- Confounder를 통제하면 경로가 닫힘

## 4️⃣ 양수성 가정 (Positivity Assumption)

### 정의
- 교란 편향을 보정하기 위해 **조건부 독립성 가정과 함께** 반드시 필요
- 공변량(X)이 **모든 수준에서 관측 가능**해야 한다는 의미
- 이 조건이 충족되지 않으면 교란 편향 보정이 불가능

### 의미
- 가능한 **모든 케이스를 관찰**해야 함
- 선택 편향을 피하기 위해 모든 특성에 반영되는 샘플을 확보해야 함

### 실무 적용
```
예시: 전국민 평균 체중과 교육 수준 계산

문제:
- 특정 그룹(예: 인바디 측정자)만의 데이터 존재
- 측정하지 않은 사람들의 데이터는 없음

해결:
- 없는 데이터를 다른 데이터셋에서 보완
- 인터폴레이션으로 추정하여 전체 집단에 포함
```

### 공정한 샘플링
- 모든 사람에게 접근하여 확인
- 쌍둥이 샘플과 개별 샘플을 모두 활용
- 샘플 자체의 바이어스를 고려
