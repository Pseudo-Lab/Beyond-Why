# CH 9 . 통제집단합성법

1. 통제집단합성법
- 하나의 처치 단위(eg. 특정한 지역이나 회사 등 유닛) 에 대한 정책,사건, 이벤트 등의 효과를 추정하기 위해 여러 대조 단위를 적정한 가중치로 결합하여 처치가 없었을 때의 가상 처치 단위를 만드는 방법
- 이중차분법의 평행추세 가정이 깨질 때 매우 유용
- N=1 (처치 단위 1개) 일 떄도 적용 가능
- 처치 이전 기간의 데이터를 활용해서 대조 단위들의 가중합이 처치 단위의 과거 패턴을 가장 잘 재현하는 합성 통제집단(synthetic control)을 생성

2. SCM 수학적 구조 및 최적화
- $$min∥X_1−X_0w∥^2 s.t. w≥0,∑w_i=1$$
- $$X_1$$ : 처치 단위의 처치 이전(pre- treatment)에서 여러 시점의 결과값 벡터
- $$X_0$$ : 여러 대조 단위의 처치 이전에 여러 시점에서 파생한 결과값의 행렬
- $$w$$ : 각 대조 단위에 부여할 가중치 벡터로 양수이며, 합은 1이어야 함

제약조건
$$w_i >= 0$$ : 음의 가중치 금지 → 외삽(extrapolation) 방지
$$∑w_i=1$$ : 볼록조합(convex combination) > 합성 통제집단이 실제 대조 단위들의 가중 평균

3. ATT추정과 시각화
- 합성 통제집단 $$Y_0(t) = ∑w_iO(t)$$ 을 만든 후 $$ATT(t) = Y_1(t) - Y^_0(t) (t>=T_0)$$
- $$Y_1(t)$$: 처치 단위의 실제 결과 (처치 후)
- $$Y_0^(t)$$: 합성 통제집단의 결과 (처치 후 예측값)
플롯으로 처치 전: 두 선이 거의 겹침, 처치 후: 처치 단위가 위로 벌어짐 → 시각적 효과 확인

4. 임의 숫자 예시 : 캘리포니아 담배규제법 효과
- 상황 : 캘리포니아에 담배규제법 시행 , 다른 37개주(대조군) 통제집단
- 처치 이전 5년간 1인당 담배 소비량(임의 단순화)


| 연도   | 캘리포니아(X₁) | 뉴욕  | 텍사스 | 플로리다 | ... (기타 34주) |
| ---- | --------- | --- | --- | ---- | ------------ |
| 1983 | 120       | 110 | 130 | 115  | ...          |
| 1984 | 118       | 108 | 128 | 113  | ...          |
| 1985 | 115       | 105 | 125 | 110  | ...          |
| 1986 | 112       | 103 | 122 | 108  | ...          |
| 1987 | 110       | 100 | 120 | 105  | ...          |

- SCM 최적화 결과 (가중치 w): 뉴욕: w₁=0.4, 텍사스: w₂=0.3, 플로리다: w₃=0.2, 기타: w₄~₃₇=0.1

합성 캘리포니아(처치 이전 재현):
- 1983: 0.4×110 + 0.3×130 + 0.2×115 + 0.1×평균 = 120 ✓
- 1984: ... = 118 ✓ (거의 완벽 재현)

처치 후(1988~1990) 실제 vs 합성:
| 연도   | 실제 캘리포니아 | 합성 캘리포니아 | ATT(효과) |
| ---- | -------- | -------- | ------- |
| 1988 | 95       | 108      | -13     |
| 1989 | 92       | 105      | -13     |
| 1990 | 90       | 102      | -12     |


해석: 담배규제법으로 캘리포니아 1인당 소비량이 연평균 12~13개비 감소 → 정책 효과 확인.

5. SCM의 핵심 가정
- 처치 이전 완벽 재현: 합성 통제집단이 처치 단위의 과거 패턴을 완벽히 재현해야 함
- 비기대 가정: 처치가 랜덤하게 배정되었다고 가정 (이중차분법과 동일)
- 무간섭 가정: 처치가 다른 단위에 영향을 주지 않음 (SUTVA)
- 공변량 안정성: 처치 이전 특성들이 처치 후에도 유사하게 작용

6. SCM과 이중차분법 비교 및 확장

| 구분      | 이중차분법(DID)          | 통제집단합성법(SCM)       |
| ------- | ------------------- | ------------------ |
| 적합 상황   | N>>T (많은 단위, 짧은 기간) | T>>N (긴 기간, 적은 단위) |
| 가정      | 평행추세                | 처치 이전 완벽 재현        |
| 가중치     | 등가중(1/N)            | 최적화로 결정            |
| N=1 가능? | 불가                  | 가능                 |


합성 이중차분법(SC-DID): 두 방법 결합으로 평행추세 가정을 강화하고, 시간 가중치도 최적화.


9. 실무 적용 예시
- 정책 평가: 특정 시도에만 시행된 최저임금 인상법 효과
- 기업 이벤트: 한 지점만의 대형 할인 행사 매출 효과
- 게임 업데이트: 특정 서버만의 밸런스 패치 효과
- 의료 개입: 한 병원만의 신규 치료법 도입 효과

8. 장점과 한계
장점:
- N=1에서도 사용 가능
- 시각적 직관성(그래프 한눈에 효과 확인)
- 평행추세 가정보다 "과거 완벽 재현" 가정 더 설득력 있음
한계:
- 대조 단위 수가 적으면 가중치 추정 불안정
- 공변량(특성) 미포함 기본 버전의 한계
- 추론(신뢰구간)이 복잡하고 계산 비용 높음

이중차분법이 "평균 집단 수준" 효과를 추정한다면, SCM은 **"특정 단위의 개별화된 효과"**를 정교하게 추정하는 준실험 방법으로 자리잡는다고 생각할 것
