## * 학습 내용 요약

### * 처치 - 결과 사이가 비선형적인 경우
- 배경: 선형회귀모델은 처치 - 결과 사이 관계가 선형적이라고 가정함
- 문제: 처치 - 결과 사이 관계가 비선형적 (처치-반응 그래프가 선형이 아님)
- 대응: 처치 - 결과 사이를 선형 관계로 변환하는 함수를 찾아 관계 보정
- 추가: 비선형 데이터에 FWL 정리 적용 방법
    - (1) 처치(T)와 결과(Y) 사이를 선형적으로 만드는 함수 F 정의
    - (2) 편향 제거: 교란변수로 F(T)를 예측하는 회귀모델 적합 후 처치잔차 구함(=F(T) - hat(F(T)))
    - (3) 잡음 제거: 교란변수로 Y를 예측하는 회귀모델 적합 후 결과잔차 구함(=Y-hat(Y))
    - (4) 인과추정량 계산: 처치잔차로 결과잔차 예측하는 모델 적합 후 회귀계수 해석

### * 이상적인 무작위 통제 실험을 못 하는 경우
- 배경: 이상적인 무작위 통제 실험(RCT) 하기 어려운 경우
- 대안: 조건부 무작위 실험
- 내용: **공변량을 조건부로 하여** 처치를 어떤 분포에서 랜덤하게 추출한 값으로 배정 : T ⊥ (Y0, Y1) | X (조건부 독립)
- 노트:
    - 조건부 무작위 실험은 비용은 더 저렴하지만 훨씬 복잡함
    - 공변량에 따라 적은 수의 그룹을 생성하는 것이 분석에 유리
    - 그룹간 처치 분포가 중첩될수록 분석 용이

### * 변수를 누락한 경우 생기는 편향을 알고 싶은 경우 (누락변수편향)
- 배경: 어떤 변수를 누락하는 경우 처치변수에 대한 회귀계수에 편향 발생 **(누락변수편향; OVB; Omitted Variable Bias)**
- 목적: 어떤 변수의 포함 여부가 처치변수 회귀계수 편향이 얼마나 생기는지 알고 싶음
- 정리:
    - 어떤 변수를 누락했을 때 처치변수에 대한 회귀계수 편향은 아래의 값과 비례
    - (1) 누락변수(OV)로 결과변수(Y)를 설명하는 양과 비례
    - (2) 처치변수(T)로 누락변수(OV)를 설명하는 양과 비례
    - **⇒ 누락변수가 결과변수 / 처치변수와 관련이 클수록 누락편향은 커짐 (당연한 이야기)**

```python
df = pd.read_csv("data/risk_data.csv")

# 변수 누락 / # 변수 포함
model_short = smf.ols("default ~ credit_limit", data=df).fit()
model_long = smf.ols("default ~ credit_limit + wage", data=df).fit()

model_omitted = smf.ols("wage ~ credit_limit", data=df).fit()

biased_credit_limit_coef = model_short.params["credit_limit"]
unbiased_credit_limit_coef= model_long.params["credit_limit"]

# 누락변수가 결과변수를 설명하는 정도
wage_coef_in_long_model = model_long.params["wage"]
# 처치변수가 교란변수를 설명하는 정도
credit_limit_coef_in_aux_model = model_omitted.params["credit_limit"]

# 누락변수 편향
print(round(biased_credit_limit_coef - unbiased_credit_limit_coef, 8)) # -2.628e-05
# 누락변수 편향 측정 방법
print(round(wage_coef_in_long_model * credit_limit_coef_in_aux_model, 8)) # -2.628e-05

```


### * 변수 포함/제외 여부에 따른 인과추정량 편향/분산 영향
- (1) 처치/결과의 **충돌변수** → 무조건 제외
    - 포함 시 인과경로에 거짓상관 유도하여 무조건 모델에서 제외해야 함
- (2) 처치/결과의 **공통원인**(교란변수) → 편향/분산 trade-off 관계 고려하여 선택
    - 교란변수를 더 포함할수록 → 인과추정량 편향 감소 / 분산 증가
    - 교란변수를 덜 포함할수록 → 인과추정량 편향 증가 / 분산 감소
    - ⇒ **처치의 강력한 예측자이고 결과의 약한 예측자인 경우 분산 감소를 목적으로 제외 고려**
- (3) 기타
    - 처치는 설명하지만 결과는 설명하지 않는 변수 포함 → 인과추정량 편향 무관 / 분산 감소
    - 결과는 설명하지만 처치는 설명하지 않는 변수 포함 → 인과추정량 편향 무관 / 분산 증가
    - 처치와 결과 모두 설명하지 않는 변수 포함 → 인과추정량 편향 무관 / 분산 무관


### * 교란편향을 보정하는 또 다른 방법, 성향점수(PS; Propensity Score)
- **정의: 공변량(X)이 주어졌을 때 처치(T)를 받을 조건부 확률 = e(x) = P(T=1|X)**
    - 아쉽게도 현실에서는 처치 배정 메커니즘을 알 수 없는 경우가 대부분이기 때문에
    - 실제 성향점수를 알 수는 없고 대부분 **성향점수 추정치를 사용**
    - 성향점수 추정 모델로는 로지스틱 회귀 모델 뿐만 아니라 ML/DL 모두 활용 가능함 (확률값만 구해진다면!)
- **특징: 처치가 이진 혹은 이산형일 때 적합**
    - 처치가 연속형 일 때는 성향점수를 조건부 확률밀도함수 값으로 대체하기도 함 (아래에서 서술)


### * 성향점수를 이용한 보정 방법을 알아보기 전
- **성향점수를 이용해 보정하려면, 성향점수를 잘 구하는 것이 매우 중요함**
    - 성향점수 추정치가 부정확한 경우 성향점수를 보정하여 구한 인과추정량 역시 잘못 구해졌을 가능성 높음
- **그렇다면 성향점수를 잘 구하면 모든 문제가 해결될까? 아니다, 편향-분산 문제가 기다리고 있음**
    - 이전에 배웠던 내용을 다시 상기해보면
    - T는 잘 설명하지만 Y는 잘 설명하지 못 하는 X가 있다면
    - 이러한 변수를 모델에 많이 포함할수록 편향은 줄어들지만 분산은 커짐 (편향-분산 Trade-Off)
- **성향점수의 예측력이 매우 좋으면 오히려 반사실을 구하기 어려워짐**
    - 정확도 매우 높은 성향점수 추정 모델을 구했다고 가정해보자
    - 대조군에서는 성향점수가 매우 낮고, 실험군에서는 매우 높다면
    - 반사실을 추정할 수 있는 개체가 별로 없는 상황을 마주하게 됨
- **처치효과를 가장 잘 추정할 수 있는 무작위 처치 배정 실험의 경우 성향점수 예측 모델 정확도 0임**
- **→ 편향을 통제할 수 있을 정도로 정밀하게 성향점수 추정 모델을 만들되, 너무 과도하면 분산 문제 발생 가능**


### * 성향점수를 이용한 교란편향 보정: (1) 회귀모델에 반영하기
- 방법: 회귀모델에 공변량 대신 성향점수를 반영하기 (04장에서 다루었던 내용과 연관)
- 특징: 모델에 공변량을 반영했을 때 구해진 ATE값과 성향점수를 반영했을 때 구해진 ATE는 매우 유사함


### * 성향점수를 이용한 교란편향 보정: (2) 매칭 추정량(PSM; Propensity Score Matching)
- 방법: 성향점수가 유사한 대조군(T=0)과 처치군(T=1)을 짝지어 관측되지 않은 반사실 추정
    - 대조군: 각 대조군 개체에 대해 성향점수가 가장 가까운 처치군 개체를 KNN으로 찾고, 처치군의 Y값을 이용해 Y1 예측
    - 처치군: 각 처치군 개체에 대해 성향점수가 가장 가까운 대조군 개체를 KNN으로 찾고, 대조군의 Y값을 이용해 Y0 예측
- 특징:
    - 분산 추정 어려움
    - 교란변수 차원 클수록 데이터가 희소해져 편향 커짐
    - 💡KNN 대신 K-d Tree, LSH 등의 알고리즘을 사용하기도 함
        - 이 경우는 성향점수를 사용하는 것이 아니라 공변량을 이용해 유사한 개체를 찾는 방법임
        - 성향점수를 사용하지 않고 공변량을 직접 사용하기에 모델에 의존적이지 않음
        - 다만 계산 효율성을 높이기 위는 것이 필요하여 고속 탐색 알고리즘을 주로 사용함

### * 성향점수를 이용한 교란편향 보정: (3) 역확률 가중치(IPW; Inverse Propensity Weighting)
- 방법: 성향점수를 이용해 **데이터의 가중치를 재조정하여 처치가 무작위 배정된 것처럼 보이게 함**
- 특징:
    - 회귀모델에서 성향점수 반영하여 구한 ATE와 매우 유사함
    - **IPW 추정값의 신뢰구간을 얻을 수 있는 가장 간단한 방법은 부트스트랩 이용하는 것**
        - 데이터를 반복적으로 복원추출해서 여러개의 IPW 추정값 구할 수 있음
        - 추정값의 2.5번째와 97.5번째 백분위수를 계산하여 95% 신뢰구간을 얻을 수 있음
    - **성향점수가 매우 작은 경우(이상치) → 역확률 가중치가 매우 커져 → 추정값의 분산이 커짐**
        - 문제: 처치 배정 확률이 매우 낮은 경우 P(T=1|X)가 작아져 계산상의 문제 발생 가능
        - 대응: w = **P(T=t)** / P(T=t|X) 사용 (← 가중치가 너무 커지는 문제 완화)
        - 장점: ATE의 기댓값은 동일하나 **ATE 추정치의 분산이 줄어듦**


### * 성향점수를 이용한 선택편향 보정: 역확률 가중치(IPW)
- 방법: 성향점수를 이용하여 가중치 조정
- 사례: 만족도 조사를 이메일 랜덤 발송 → 응답된 이메일 대상으로 평균 만족도 구함
    - 선택 편향 발생: 만족도 높은 유저는 이메일 응답 확률 높고, 만족도 낮은 유저는 이메일 응답 확률 낮은 선택편향 발생
    - 선택 편향 보정: 응답할 확률을 예측하고, 이 확률의 역확률을 가중치로 사용하여 유사 모집단 생성하여 분석 진행


### * 성향점수의 양수성 가정
- **더 많은 변수를 추가하여 e(x)에 대한 모델을 정교하게 만들수록 양수성 가정의 타당성 떨어짐**
    - IPW 재구성은 재조정할 수 있는 표본이 있을 때만 가능함
    - 대조군은 성향점수 낮은 영역에 몰려있고, 실험군은 성향점수 높은 영역에 몰려있다면 (← 양수성 가정 위배)
    - 대조군/실험군 결과에 대해 반사실 재구성하는 재조정 불가함
- **PS가 매우 작아 역확률 가중치가 커지면 추정치의 분산도 커지는 문제도 덩달아 발생**
- **→ 외삽이 필요한 경우 IPW를 사용해도 ATE를 정확하게 추정하기 어려움**
    - 회귀분석은 E[Y|T, X]에 대한 모수적인 가정으로 양수성 가정 대체 가능
    - 선형모델이 조건부 기댓값을 잘 반영한다면 양수성 가정이 유지되지 않는 영역에서도 ATE 구할 수 있음
    - 하지만 IPW는 잠재적 결과의 형태에 대해 아무런 가정도 하지 않기 때문에
    - 외삽이 필요한 경우 IPW는 ATE를 정확하게 추정하기 어려움


### * 모델 기반 식별 vs. 디자인 기반 식별 vs. 이중강건(DR)
- **모델 기반 식별**: 처치 및 공변량을 조건부로 설정하고 잠재적 결과에 대해 모델 형태로 가정
    - 사용 조건: 함수형 관계가 잘 알려져있을 때 (혹은 잘 예측할 수 있을 때)
    - 예시: 회귀분석(잠재적 결과 예측), 통제집단합성법(9장 예정)
- **디자인 기반 식별**: 처치 배정 메커니즘에 대해 가정
    - 사용 조건: 처치 배정에 대해 잘 이해하고 있는 경우
    - 사용 예시: 회귀분석(FWL), 성향점수매칭, 역확률가중치
- **이중 강건 추정**(DR; Doubly Robust) = 모델 기반 식별 + 디자인 기반 식별
    - 사용 장점: 둘 중 한 가지만 정확하게 지정해도 효과가 있는 방법 (둘 중 하나는 틀려도 됨)

$$ 
ATE={\hat{\mu}}_{1}^{DR}(\hat{m}, \hat{e}) - {\hat{\mu}}_{0}^{DR}(\hat{m}, \hat{e})
$$


### * 연속형 처치에서의 일반화 성향점수
- 문제:
    - 처치가 연속형 변수인 경우 잠재적 결과도 무한히 많이 존재함
    - 연속형 변수의 확률은 항상 0이므로 성향점수(=P(T=t|X)) 추정 불가
- 해결:
    - (방법 1) 연속형 처치를 이산화하는 것
    - (방법 2) 일반화 성향점수(GPS; Generalized Propensity Score) 사용
        - 조건부 확률분포 대신 조건부 확률밀도를 사용하면 됨
        - 다만 이 때 어떠한 확률분포를 가정할 것인지 정의해야 한다는 문제 존재 (책에서는 정규분포 가정)
        - **조건부 확률밀도 값을 역가중치로 사용하여 추정하면 됨**
            - ipw = 1 / f(t|x)
        - 다만, 처치가 연속형 변수일 경우 가중치 안정화를 필수로 사용해야 함 (편향/분산 모두 낮춰줌)
            - generalized_ipw = f(t) / f(t|x)
