# Chapter 4

## 1. 비선형성과 양수성

- **양수성 - positivity**  
  모든 조건 X 에 대해 "처치받은 사람과 받지 않은 사람"이 둘 다 존재해야 한다는 조건.  
  즉, 어떤 집단에서 한쪽 처치군 만 있다면 효과를 비교할 수 없고 "외삽 extrapolation"이 필요함.  
  외삽은 모델 가정에 의존하기 때문에 위험함 → 추정이 불안정해질 수 있음.  
  ⇒ 보완책: 가중치 IPW, 이중강건 DR, 지역적 추정 같은 방법 활용.

- **비선형성 문제**  
  결과와 처치의 관계가 단순히 직선이 아닐 수 있음.  
  예: log 나 제곱근을 쓰거나, 스플라인 또는 다항식으로 관계를 부드럽게 근사.  
  이렇게 하면 "부분선형모형 partial linear model" 로 표현 가능.  
  이 모델은 X 의 복잡한 효과는 비모수적으로 처리하고, 관심 있는 처치 효과만 깔끔히 추정함.

## 2. FWL 원리와 비선형 확장

- **1단계: 처치 정리 Residualization**  
  처치 T 가 X 와 어떤 관계인지 먼저 회귀로 예측하고,  
  예측된 값을 빼서 "X 의 영향을 제거한 순수한 처치값"을 만듦.

- **2단계: 결과 정리**  
  결과 Y 도 X 에 대해 회귀 후 잔차를 구함.  
  즉, X 로 설명되는 부분을 제거해 순수한 효과만 남김.

- **3단계: 순수한 효과 계산**  
  위 두 잔차를 단순 회귀하면 인과효과 추정치 베타 가 됨.  
  이건 "이중 추정 double or debiased" 개념이라 머신러닝 기반 1단계 추정에도 적용 가능.

- **요약:**  
  X 의 영향을 미리 제거하고, 남은 순수 관계만으로 효과를 보는 아이디어.  
  FWL 정리의 비선형 버전이라 보면 됨.

## 3. 더미 변수와 조건부 무작위성

- **왜 더미 변수를 쓰나**  
  완전한 무작위 실험이 어렵기 때문.  
  그래서 공변량 X 에 따라 여러 그룹으로 나눠서 "그룹 내에서는 무작위"처럼 보이게 함.  
  예: 소득수준별, 연령대별 실험 → 각 그룹은 작은 RCT처럼 작동.

- **더미 변수의 역할**  
  각 그룹을 표시하는 변수 0 또는 1 로, 그룹별 평균 차이를 직접 모델에 넣는 방식.  
  기준 base 그룹 대비 차이를 보는 형태라 해석이 간단하지만,  
  더미를 너무 많이 넣으면 다중공선성 문제 dummy trap 이 생김.

## 4. 상호작용 Interaction 과 그룹별 효과

- **상호작용항이란**  
  "처치 효과가 그룹마다 다를 수 있다"는 걸 표현.  
  예: 나이그룹별, 성별 등 → T 곱하기 Gk 형태로 추가.

- **해석 요약:**  
  - 기준 그룹 G1 의 효과 = tau  
  - 다른 그룹 Gk 의 효과 = tau + delta k  
  - 즉, delta k 가 0 이 아니면 그룹별로 효과가 다름.

- **포화모형 Saturated model**  
  모든 그룹과 상호작용을 다 포함한 회귀식.  
  이건 결국 그룹별 평균 비교와 똑같은 결과를 줌.  
  단, 너무 많은 변수를 넣으면 표본이 적을 때 분산이 커질 수 있음.

- **주의점**  
  - 그룹 내 표본 수가 적으면 추정이 불안정.  
  - 너무 많은 그룹은 다중비교 문제 발생.  
  - robust 표준오차나 보정 필요.

## 5. 누락 변수 편향 OVB

- **문제 상황:**  
  중요한 변수 Z 를 빼먹고 단순회귀하면,  
  그 변수의 영향이 처치와 결과 모두에 섞여 편향이 생김.

- **편향 방향:**  
  누락변수가 Y 와 T 모두에 영향을 주면 → 편향 발생.  
  편향은 Z 가 Y 에 미치는 영향과 Z 가 T 에 미치는 영향의 곱만큼 생김.

- **해결책:**  
  - 가능한 한 Z 를 측정해 포함  
  - 도구변수 IV 사용  
  - 고정효과 FE 나 차분 DID 로 시간불변 요인 제거  
  - 무작위화로 공변량 통제

## 6. 중립 통제변수와 변수 선택

- **중립 변수 Neutral Control:**  
  편향은 줄이지 않지만 분산을 줄이는 변수들.  
  예: Y 에는 영향 있지만 T 와는 상관없는 변수.

- **Bias–Variance Tradeoff:**  
  변수를 많이 넣으면 편향은 줄지만 분산이 커짐.  
  반대로 변수를 적게 넣으면 분산은 줄지만 편향이 늘어남.  
  실제 연구에서는 둘 사이 균형이 중요함.

- **변수 선택 기법:**  
  - Ridge, LASSO, Elastic Net 등 규제 회귀  
  - 교차검증으로 최적 조합 선택  
  - Double Selection 처리와 결과 모두 예측에 쓰인 변수만 선택  
  - 최근엔 DML Double Machine Learning 로 고차원 데이터에서도 안정적 추정 가능.


# Chapter 5 


## 1. 성향 점수 PS Propensity Score

- 성향 점수는 "어떤 사람이 처치를 받을 가능성" 을 요약한 확률값임.  
- 보통 로지스틱 회귀나 머신러닝 모델로 추정함.  
  예: 나이, 성별, 소득, 학력 등을 입력하면, 이 사람이 프로그램에 참여할 확률을 계산함.  

- 이렇게 계산된 점수를 이용하면 복잡한 X 변수 대신 하나의 수치로 비슷한 사람을 찾을 수 있음.  
  즉, 여러 변수의 조합을 하나의 축으로 요약하는 셈임.  

- **분석 절차 예시**
  1. 모든 표본에 대해 처치 받을 확률 e X 를 추정  
  2. 비슷한 e X 를 가진 처치군과 대조군을 매칭  
  3. 두 집단의 평균 차이로 ATE 평균처치효과 추정

- **의의**
  - 공변량이 여러 개인 경우에도 단순 비교가 가능해짐.  
  - 차원의 저주를 완화하고, 회귀식의 복잡도를 낮춤.  
  - 다만 완벽한 무작위화를 보장하지는 않음.  

## 2. 역확률 가중치 IPW Inverse Probability Weighting

- PS 매칭은 일부 데이터가 짝지어지지 않으면 버려질 수 있음.  
  반면 IPW 는 모든 표본을 활용하면서도 무작위 배정된 것처럼 만드는 방법임.

- **아이디어**
  - 처치를 받은 사람은 1 나누기 e X 의 가중치,  
  - 처치를 받지 않은 사람은 1 나누기 1 빼기 e X 의 가중치를 부여함.  
  - 이렇게 하면 데이터 전체가 "균형 잡힌 인공 모집단" 으로 재구성됨.

- **절차 요약**
  1. 각 표본의 성향 점수를 계산  
  2. 위의 식으로 가중치를 계산해 분석에 적용  
  3. 가중된 평균을 계산해 두 집단의 차이를 추정

- **장점**
  - 표본 손실 없이 전체 데이터를 활용할 수 있음  
  - 결과적으로 PS 매칭보다 효율적일 수 있음  

- **유의점**
  - 극단적인 e X 값 0 또는 1 근처의 표본은 너무 큰 가중치를 받아 불안정해질 수 있음.  
  - 따라서 트리밍, 윈저라이징 등으로 극단값을 제어함.  

  ## 3. 편향과 분산의 균형 Bias–Variance Tradeoff

- 변수를 많이 넣거나 복잡한 모델을 사용하면 편향은 줄지만 분산이 커짐.  
- 반대로 단순한 모델을 쓰면 분산은 줄지만 편향이 커질 수 있음.  
- 따라서 매칭이나 가중추정에서도 이 균형을 고려해 선택해야 함.  
  예를 들어 지나친 trimming 은 편향을 줄이지만 분산을 키울 수 있고,  
  반대로 완전한 포함은 분산을 줄이지만 왜곡된 표본을 남길 수 있음.
