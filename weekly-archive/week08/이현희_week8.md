## 4장. 유용한 선형회귀

### 1) 양수성(positivity) & 외삽(extrapolation)
- 정의: 모든 X 조합에서 0 < P(T=1|X) < 1 이어야 함. 겹침(common support)이 없으면 식별 불가.
- 외삽 위험: 한쪽 처치가 거의 없는 영역에서 회귀계수는 **모형가정에 의존**(=취약).
- 점검: T=1/0의 X 분포 겹침(히스토그램·커널), 극단값 트리밍, 성향점수 분포 시각화.
- 보완: 지역적 추정(근접 매칭), IPW·이중강건(DR), 오버랩 가중치.

### 2) 선형회귀에서의 비선형성
- 반응함수 비선형 → 변환(log/sqrt), 다항·스플라인·분할회귀.
- 부분선형모형(PLM): Y = T*β + g(X) + ε (g: 비모수). FWL 아이디어로 β 추정 가능.
- 실무 팁: 여러 변환 후보 F(T), g(X) 사양을 돌려 **민감도 분석**(표·그래프로 정리).

### 3) 비선형 FWL(직교화) 3단계
1) 처치-잔차: m_F(X) ≈ E[F(T)|X],  tilde_F = F(T) - m_F(X)  
2) 결과-잔차: g(X) ≈ E[Y|X],         tilde_Y = Y - g(X)  
3) 최종: tilde_Y ~ tilde_F (robust SE)
- 과적합 완화: 교차적합, 표준오차는 샌드위치/부트스트랩.

### 4) 더미변수 회귀 & 포화 사양
- 조건부 무작위화 가정 하에, X 범주화·상호작용으로 그룹 내 평균차를 직접 추정.
- 기준범주 포함형: Y = α + τT + Σ γ_k G_k + Σ δ_k (T×G_k) + e  
  - 기준그룹 효과 = τ, 그룹 k 효과 = τ + δ_k
- 무절편(cell-mean)형: Y = Σ β_k G_k + Σ θ_k (T×G_k) + e  
  - 그룹 k의 평균차 = θ_k
- 유의: 더미트랩, 표본 불균형, 다중비교 보정, 이분산 robust SE.

### 5) 누락변수편향(OVB) 공식(상세)
- 진짜: Y = τT + β'Z + u.  추정: Y ~ T만 ⇒ hat{τ} = τ + β'δ,  
  - δ: 보조회귀 T ~ Z 의 계수벡터(즉 Z가 T에 미치는 영향).  
  - 편향 = (Z→Y 영향) × (Z→T 영향).
- 완화: Z 포함/대리변수, 설계(무작위화), 패널 FE/차분(DID), 도구변수(IV).

### 6) 중립 통제변수 & 분산관리
- 중립 통제: T와는 독립이나 Y와 연관 → 편향은 X, 분산↓ 가능.
- 고차원: 규제(Ridge/LASSO), Double Selection, DML(직교화+교차적합).

## 5장. 성향점수(Propensity Score, e(X)) — 작업중_

### 1. 정의·핵심 정리
- e(X) = P(T=1|X).  
- 강한 비혼합성(선택 무관성): (Y(1), Y(0)) ⟂ T | X.  
- 균형 성질(balance): T ⟂ X | e(X).  ⇒ X 전체 대신 **스칼라 e(X)**로 균형화 가능.
- 필요 가정: (i) 선택 무관성, (ii) 양수성 0 < e(X) < 1, (iii) SUTVA(간섭 없음).

### 2. 추정과 진단
- 추정: 로지스틱/프로빗, 또는 ML(GBM, RF, NN 등). 교차검증으로 과적합 관리.
- 진단(매칭/가중치 적용 전후 비교):
  - 표준화 평균차(SMD): |mean_t - mean_c| / sd_pool. 일반 기준: |SMD| < 0.1~0.2.
  - Love plot/히스토그램으로 e(X) 겹침 확인, 극단값 확인(0 또는 1 근처).
  - 공통지지 밖 관측치 트리밍/절단(cutoff, caliper).

### 3. 사용법 4가지
1) **매칭(Matching)**  
   - 최근접(NN) 1:1 또는 m:n, 교체허용 권장, caliper(예: 0.2·SD(logit e(X)))로 질 개선.  
   - 결과추정: 매칭쌍 평균차(ATT) 또는 가중 평균차. 표본 수 감소·표준오차 증가 주의.
2) **성향점수 가중치(IPW)**  
   - ATE 가중치: w_i = T_i/e_i + (1-T_i)/(1-e_i).  
   - ATT 가중치(처치집단 기준): w_i = 1 (T=1), w_i = e_i/(1-e_i) (T=0).  
   - 안정화 가중치(SW): 분자에 P(T=t) 추가 → 분산↓.  
   - 극단 가중치 완화: 클리핑(예: e∈[0.01, 0.99]), 트리밍, 오버랩 가중치 w ∝ e(1-e).
3) **층화/분할(Stratification/Subclassification)**  
   - e(X) 분위수(예: 5분위)로 층화 후, 각 층의 평균차를 가중 결합. 간단·직관적.
4) **이중강건(DR, AIPW)**  
   - 결과모형 μ_t(X)와 e(X)를 동시에 사용: 한쪽 모형이 틀려도 일관성(대수적 한계에서).  
   - ATE 추정량(스케치):  
     psi_i = μ_1(X_i) - μ_0(X_i)  
     + T_i*(Y_i-μ_1(X_i))/e_i - (1-T_i)*(Y_i-μ_0(X_i))/(1-e_i)  
     hat{τ} = 평균(psi_i).

### 4. 분산·표준오차
- 샌드위치(로버스트) 또는 부트스트랩. 매칭은 쌍 단위 재표본화 권장.
- 가중치 사용 시 HC3/HC2, 또는 가중 최소제곱(WLS)·회귀보정으로 효율 개선.

### %. 주의할 함정
- 약한 겹침/양수성 위반: 극단 가중치 폭증 → 추정량 불안정. 트리밍·오버랩 가중치 적용.
- 잘못된 사양: e(X)·μ_t(X) 둘 다 점검(플롯/치우침). 상호작용·비선형 누락 주의.
- 공변량 선택: 처치와 결과 **공통 원인** 위주로. 순수 결과예측 변수만 추가 시 분산만 증가.
- 표본 외 예측(외삽) 최소화: 공통지지 내에서 해석.
