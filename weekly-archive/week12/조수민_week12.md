# 이중차분법

## 1. 패널데이터란?
패널데이터는 **동일한 개체를 여러 시점에 걸쳐 반복 관측한 데이터 구조**
한 시점에 서로 다른 개체만 관측하는 횡단면 자료와 달리, 패널데이터는 시간의 흐름을 담고 있기 때문에 개체 내부의 변화와 외부 요인을 동시에 살펴볼 수 있음

패널데이터의 가장 큰 장점은 **개체가 원래부터 가진 차이를 자연스럽게 통제**할 수 있다는 점.

## 2. DID가 필요한 이유

 단순히 '전후 비교'만 하면 외부 요인의 영향을 배제할 수 없다.
 > DID는 실험군과 대조군의 변화를 비교해 **개입의 순수 효과만 분리해내는 방법**이다.

핵심 아이디어:

- 실험군은 개입 때문에 변함  
- 대조군은 개입이 없으므로 자연적 변화만 반영  
- **실험군 변화 − 대조군 변화 = 개입 효과**

시간에 따른 외부 요인(트렌드), 계절성, 전체 시장 변화 등을 제거하는 방법

## 3. DID가 작동하는 이유

패널데이터에서는 결과값을 개체 고정효과, 시간 고정효과, 개입 효과의 조합으로 생각할 수 있음.
고정효과는 관측된 변화에서 제거할 수 있으므로, 남은 부분을 개입의 효과로 해석할 수 있다.

즉, DID는  
1) 각 개체가 가진 원래 차이를 제거
2) 모든 개체가 동시에 겪는 Global한 공통 변화를 제거  
3) 개입 때문에 달라진 변화만 추출

## 4. DID의 핵심 가정: 평행추세

DID에서 가장 중요한 가정은 **평행추세(Parallel Trends)** 
> 평행추세: 개입이 없었더라도 실험군과 대조군이 비슷한 추세로 변했을 것이라는 가정 
전후 비교만으로는 확인할 수 없지만, 개입 이전 기간의 변화 패턴이 비슷하다면 어느 정도 설득력을 가질 수 있음

이 가정이 깨지는 대표적 사례:
- 실험군은 원래 상승 추세, 대조군은 정체된 추세였던 경우  
- 개입 이전부터 두 집단 간 구조적 차이가 존재할 때  
- 정책 실행 지역과 주변 지역 간 영향이 서로 섞여버릴 때 (공간적 간섭)

## 5. DID에서 추론할 때 주의점

패널데이터는 같은 개체가 반복 관측되기 때문에 독립성이 깨진다. 
이를 해결하기 위해 **군집 표준오차(clustered SE)**를 사용하기도 함.
