## 1. 메타러너(meta-learner) 

- 원래 목적: X로 Y를 잘 예측하는 **예측모델**  
- 변형 목적: 예측모델을 조합해 **누가 처치를 받으면 더 이득인지(CATE)**를 추정
  
- 특징  
  - Outcome modeling 기반임.  
  - 고차원, 비선형, 복잡한 표현 학습에 강함.  
  - 직교화(IPW, FWL) 없어도 동작 가능하나, R-learner는 이를 포함함.  
- 핵심 전제  
  - **비교란성 가정**이 반드시 성립해야 함.  
  - 아니면 CATE 해석이 의미 없어짐.

---

## 2. 이산형 처치 메타러너

### 2.1 T-learner (Two-model approach)

- 구조  
  - 처치군(T=1), 대조군(T=0) 각각에 대해 **별도의 예측 모델**을 학습함.  
  - 두 예측값의 차이를 CATE로 정의함.

- 장점  
  - 구조가 매우 단순하고 구현이 쉬움.  
  - 두 집단의 구조가 달라도 유연하게 학습 가능함.

- 한계  
  - **표본 불균형이 심할 때 성능 저하**됨.  
  - 데이터가 적은 쪽 모델이 **자기 정규화(self-normalization)**로 지나치게 단순해짐.  
  - 그 결과 CATE가 비현실적인 비선형 형태로 왜곡될 수 있음.

- 사용 권장 상황  
  - 표본 충분함.  
  - T=0/T=1 비율이 크게 치우치지 않음.

---

### 2.2 X-learner (Cross-learning)

- 목적  
  - T-learner의 **표본 불균형 문제를 완화**함.

- 핵심 흐름  
  1. T-learner 방식으로 기본 예측모델 학습  
  2. 반사실 값을 대체하여 pseudo-treatment-effect 생성  
  3. 두 개의 CATE 예측모델 학습  
  4. 성향점수(e(X))로 두 모델을 가중 결합

- 직관  
  - 데이터가 **많은 집단에서 학습된 정보에 더 큰 신뢰도를 부여**함.  
  - 표본 불균형 상황에서 더 안정적인 CATE 추정 가능함.

- 사용 권장 상황  
  - 실험군/대조군 표본 크기 차이가 큼.  

---

### 2.3 Domain Adaptation Learner (DAL)

- 개념  
  - X-learner의 변형 버전임.  
  - 성향점수 대신 **1 / P(T=t)** 형태의 가중치를 사용함.  
- 목적  
  - 집단 간 분포 차이를 추가로 보정하려는 확장형 방법임.

## 3. 연속형 처치 메타러너

### 3.1 S-learner (Single-model approach)

- 구조  
  - X와 T를 하나의 feature set으로 묶어 **단일 모델**을 학습함.  
  - T를 여러 값으로 변화시키며 반사실 예측 곡선을 생성함.  
  - 곡선의 기울기로 CATE를 요약함.

- 장점  
  - 구조가 단순하고 직관적임.  
  - 이진/연속 처치 모두 적용 가능함.  
  - baseline 모델로 사용하기 적합함.

- 한계  
  - 정규화가 강한 모델에서 **처치 효과가 0 쪽으로 편향**됨.  
  - T의 중요도가 작으면 T가 모델에서 무시될 수 있음.

---

### 3.2 R-learner (Residual-learner, DML)

- 핵심 아이디어  
  - FWL 정리를 머신러닝으로 확장한 방식임.  
  - X의 효과를 제거한 잔차 기반으로 인과효과를 추정함.

- 기본 절차  
  - X로 Y 예측 → Y 잔차 생성  
  - X로 T 예측 → T 잔차 생성  
  - 결과 잔차를 처치 잔차에 회귀함  

- CATE 확장  
  - 잔차 비율(Y_res / T_res)을 목표로 함.  
  - T_res²를 가중치로 사용하는 손실함수를 학습함.  
  - 이때 학습되는 함수가 τ(X) (개인별 효과)가 됨.

- 장점  
  - CATE를 직접 함수 형태로 산출 가능함.  
  - 비선형성, 고차원 데이터에 강함.  
  - 이론적으로 편향 제거 특성이 잘 정의된 방법임.

- 단점  
  - 과적합 위험이 큼.  
  - cross-fitting, 하이퍼파라미터 튜닝이 매우 중요함.

---

## 4. 방법별 사용 가이드

- T-learner  
  - 간단한 베이스라인.  
  - 데이터 충분하고 균형 잡혀 있을 때 적합함.

- X-learner  
  - 표본 불균형 상황에서 우선 고려하는 것이 좋음.

- S-learner  
  - 연속 처치에서 직관적인 반응 곡선을 보고 싶을 때 적합함.  
  - 과소추정 위험을 항상 염두에 둬야 함.

- R-learner  
  - 가장 이론적으로 강건한 접근법 중 하나임.  
  - 구현 난이도와 튜닝 부담이 큼.

---

## 5. 핵심 전제

- 모든 방법은 **비교란성 가정**에 의존함.  
- X에 중요한 교란 변수가 빠져 있으면,  
  추정되는 CATE는 인과효과가 아니라 단순 조건부 상관에 불과함.
