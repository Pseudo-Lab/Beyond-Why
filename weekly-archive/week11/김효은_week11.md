## * 학습 내용 요약
### 메타러너(Meta-Learner)
- **메타러너 = 예측 머신러닝 알고리즘을 활용하여 처치효과를 추정하는 방법**
- 메타러너를 ATE 추정에도 활용할 수 있지만, **고차원 데이터를 잘 처리하는 특성이 있어서 주로 CATE 추정에 활용**
- 메타러너에서는 다양한 예측 모델을 활용할 수 있으므로 여러 방법을 시도해보고 가장 효과적인 방법을 확인해야 함

---
### 1) 이산형 처치 메타러너

---
### * 방법 ① T러너 (Treatment-Learner)
**< 모델 학습 >**
- 대조군/실험군별로 X → Y 예측하는 모델 학습
- ㄴ 대조군(T=0) 데이터 대상으로 X → Y 예측하는 M0 모델 학습
- ㄴ 실험군(T=1) 데이터 대상으로 X → Y 예측하는 M1 모델 학습

**< 모델 예측 >**
- 개별 데이터에 대해 M1(X) - M0(X) 값으로 CATE 예측
 
**< 장점 >**
- 구현 단순 (→ 설명 쉬움)

**< 단점 >**
- 대조군과 실험군의 데이터 개수 차이가 큰 상황에서는 편향 발생
- 대조군과 실험군의 공변량 분포가 겹치지 않는 상황에서도 편향 발생

---
### * 방법 ② X러너 (Cross-Learner) ← Stacking + Ensemble
**< 모델 학습 >**
- (1) 대조군/실험군별로 X → Y 예측하는 모델 학습
- ㄴ (1-1) 대조군(T=0) 데이터 대상으로 X → **Y 예측하는 M0 모델 학습**
- ㄴ (1-2) 실험군(T=1) 데이터 대상으로 X → **Y 예측하는 M1 모델 학습**
- (2) 대조군/실험군별로 pseudo-CATE 구하기
- ㄴ (2-1) M1 이용해 대조군(T=0) 데이터 대상으로 pseudo-CATE = M1(X) - Y 구하기
- ㄴ (2-2) M0 이용해 실험군(T=1) 데이터 대상으로 pseudo-CATE = Y - M0(X) 구하기
- (3) 대조군/실험군별로 X → CATE 예측하는 모델 학습
- ㄴ (3-1) 대조군(T=0) 데이터 대상으로 X → **pseudo-CATE 예측하는 모델 T0 학습**
- ㄴ (3-2) 실험군(T=1) 데이터 대상으로 X → **pseudo-CATE 예측하는 모델 T1 학습**
- (4) 전체 데이터 대상으로 X → T 예측하는 모델(=성향점수 모델) 학습

**< 모델 예측 >**
- X 입력으로 T0(X), T1(X) 구한 뒤 → e(x)*T0(x) + (1-e(x))*T1(X) 으로 CATE 예측
- ㄴ 하나의 데이터를 두 모델에 넣는건가? YES! 두 개의 결과 중 맞을 것 같은 것에 가중치 더 부여하는 것 (앙상블)
- ㄴ 대조군 많음 → M1 모델 정확도 낮은 경향 & e(x) 낮은 경향 → M1 모델 예측값 이용하여 학습한 T0 모델 가중치 감소
- ㄴ 실험군 많음 → M0 모델 정확도 낮은 경향 & e(x) 높은 경향 → M0 모델 예측값 이용하여 학습한 T1 모델 가중치 감소

**< 장점 >**
- T러너 대비 대조군과 실험군의 데이터 개수 차이가 큰 상황에서도 성능 좋음

**< 단점 >**
- T러너 대비 튜닝해야 하는 모델이 많음 (모델 개수 5개)
- M0, M1 모델의 오차가 큰 경우 뒤의 단계에서 오차가 증폭될 수 있음

---
### * 방법 ③ DAL(Domain-Adaptive Learner)
**< 모델 학습 >**
- (1) 대조군/실험군별로 X → Y 예측하는 모델 학습
- ㄴ (1-1) 대조군(T=0) 데이터 대상으로 X → **Y 예측하는 M0 모델 학습 + 이 때 1 / P(T=1)를 가중치로 사용**
- ㄴ (1-2) 실험군(T=1) 데이터 대상으로 X → **Y 예측하는 M1 모델 학습 + 이 때 1 / P(T=1)를 가중치로 사용**
- (2) 대조군/실험군별로 pseudo-CATE 구하기 (← X러너와 동일)
- (3) 대조군/실험군별로 X → CATE 예측하는 모델 학습 (← X 러너와 동일)
- (4) 전체 데이터 대상으로 X → T 예측하는 모델 학습 (← X 러너와 동일)

**< 모델 예측 >**
- e(x)*T0(x) + (1-e(x))*T1(X) 으로 CATE 예측

**< 장점 >**
- X러너 대비 대조군과 실험군의 공변량 분포가 다를 때 맞춰주어 랜덤화된 데이터처럼 보이게 함
- → 결과적으로 교란편향을 줄이고 랜덤화된 실험(RCT)처럼 CATE를 추정할 수 있음

**< 단점 >**
- propensity 모델에 대한 의존성 증가
- P(T=t)가 작은 경우 가중치가 매우 크게 적용되어 학습 불안정

---
### 2) 연속형 처치 메타러너

---
### * 방법 ① S러너 (Single-Learner)
**< 모델 학습 >**
- (X, T) → Y 예측하는 모델 M 학습

**< 모델 예측 >**
- (이산형 처치) M(X, T=1) - M(X, T=0) 으로 CATE 예측
- (연속형 처치) T의 각 구간별로 Y 예측값 구한 뒤 (T → Y 예측값) 기울기값으로 CATE 예측

**< 장점 >**
- 랜덤화된 데이터가 없어도 괜찮은 성능을 보임
- S러너는 이진 및 연속형 처치 모두에 활용 가능

**< 단점 >**
- **처치효과를 0으로 편향시키는 경향** (트리 혹은 정규화 머신러닝 모델을 사용하면 이러한 문제는 더 심화)
- 다른 공변량 대비 처치변수가 결과를 설명하는데 영향력이 작다면 처치변수를 버릴 수 있음 (처치효과 0으로 편향)

---
### * 방법 ② R러너 (Residual-Learner)
**< 모델 학습 >**
- (1) X로 T 예측하는 모델 M_{T} 학습 → T에 대한 잔차 구함 (← 공변량에 대한 편향 제거 목적)
- (2) X로 Y 예측하는 모델 M_{Y} 학습 → Y에 대한 잔차 구함 (← 공변량에 대한 편향 제거 목적)
- (3) X로 tilde(Y)/tilde(T) 예측하는 모델 M_{C} 학습 (이 때 각 데이터의 가중치는 tilde(T)^2)

$$ Y_{i} = \hat{\mu_{y}}(X)+\tau_{i}(T_{i}-\hat{\mu_{t}}(X_{i}))+\hat{\epsilon_{i}} $$
$$ \hat{\epsilon_{i}} = (Y_{i} - \hat{\mu_{y}}(X))-\tau_{i}(T_{i}-\hat{\mu_{t}}(X_{i})) $$
$$ L=\frac{1}{n}\sum_{i=1}^{n}\hat{\epsilon_{i}}^2=\frac{1}{n}\sum_{i=1}^{n}((Y_{i} - \hat{\mu_{y}}(X))-\tau_{i}(T_{i}-\hat{\mu_{t}}(X_{i})))^2 $$
$$ L=\frac{1}{n}\sum_{i=1}^{n}\tilde{T_{i}}^2(\frac{\tilde{Y_{i}}}{\tilde{T_{i}}}-\tau_{i}(X_{i}))^2 $$

**< 모델 예측 >**
- X → M_{C} 넣어서 구한 예측값을 CATE 추정량으로 사용
- (참고) S러너는 Y값의 예측값 차이를 이용해 CATE 추정 / R러너는 CATE를 직접 예측
- (참고) P(T=t)가 큰 경우 tilde(T) 작아지는 구조 → 가중치 매우 작아짐 (정보량 없기 때문에 적절한 조치임)

**< 장점 >**
- CATE 추정값을 직접 예측
- 편향 적음

**< 단점 >**
- 구현 복잡
- 선행 모델 품질에 의존적임
