# Chapter 6. 이질적 처치효과 (Heterogeneous treatment effect)

## 1. ATE에서 CATE로
- 처치(Treatment)는 누군가에겐 큰 효과를 주지만 다른 누군가에겐 거의 효과가 없을 수 있으며 심지어 부정적인 효과가 나타날수도 있음
    - ATE 추정은 전체 모집단에서 처치 시행 여부를 결정할 때 유용하게 쓰이지만
    - ATE는 효과의 평균값일 뿐, 실제로 효과가 큰 집단, 작은 집단, 역효과가 발생하는 집단이 섞여있음. 개별 단위의 효과를 고려하지 않게 됨
- "누구에게 처치를 해야 가장 효율적인가"라는 의사결정 역시 중요함
- 개인화를 위한 한 가지 방법
    - CATE(조건부 평균 처치효과) 추정을 통해 각 실험 대상의 고유 특성을 고려
    - 특정 조건 X를 가진 사람에겐 어떤 효과가 있는가 → 부분집단(subgroup) 별로 효과를 따로 추정


## 2. 예측이 답이 아닌 이유
- 예측을 잘 한다고 해서 타겟팅도 잘 되는 것은 아님
- 예시
    - A 유저 : 구매 확률 90%, 쿠폰 효과 = +1%
    - B 유저 : 구매 확률 10%, 쿠폰 효과 = +20%
- 예측 모델은 A 유저를 "구매할 가능성이 높은 사람"으로 보지만 효과가 큰 유저는 B.
- 즉, 예측 모델은 수요가 높은 집단을 찾지만 CATE는 처치 효과가 큰 집단을 찾는다.


## 3. 회귀분석으로 CATE 구하기
- 가장 전통적이고 간단한 접근.
- 일반 회귀식에 상호작용항(interaction term)을 넣으면 됨
    - Y = α + β*T + γ*(T×X) + θX + error
        - Y : 결과(구매, 매칭, 전환 등)
        - X : 유저 특성
        - T x X : 상호작용항 → CATE를 반영하는 핵심
        - γ : 특정 X조건에서 효과가 어떻게 달라지는가
    - 예시) X가 가격민감도라면 β는 전체 평균효과(ATE), γ는 가격민감도가 1 증가할 때 효과가 얼마나 더 커지는지를 의미
    - β + γX : 유저에게 해당하는 CATE
- 단점
    - (1) 비선형 패턴을 잡지 못함
    - (2) 고차원 변수가 많으면 해석이 어려워짐
    - (3) 모델 구조에 따라 CATE 패턴이 제한됨


## 4. CATE 예측 평가하기
- CATE 예측에 대한 평가는 ML과 다름
- (1) Group-level test
    - 예측한 CATE가 높은 그룹이 실제로 더 큰 효과를 보았는가?
    - T = 1 / T = 0 차이를 그룹별로 계산해서 비교
- (2) Qini 계수 (Qini coefficient)
    - 이질적 처치효과 모델 평가 전용 지표이며 Lift curve 기반
- (3) PEHE (Precision in Estimation of Heterogeneous Effect)
    - 개별 수준 CATE 정확도 측정
    → 단, 실제 실험에서는 counter-factual이 없으므로 주로 시뮬레이션에서 사용함
- 핵심은 예측이 얼마나 정확도가 높은지가 아니라, 예측이 얼마나 '효과가 큰 대상'을 상위에 배치하는가.


## 5. 모델 분위수에 따른 효과
- CATE 모델은 어떤 대상이 처치에 더 민감한지를 찾아서 더 효율적으로 처치를 배정하려는 필요성, 즉 개인화에 대한 열망에서 시작
- 실험 대상을 민감도가 높은 순서부터 낮은 순서로 나열하는 것은 개인화를 하는 데에 용이함
- 모델 분위수에 따른 효과
    - CATE 예측값을 기준으로 유저는 10분위(또는 20분위)로 나누고 (1분위(효과가 가장 낮은), 10분위(효과가 가장 큰))
    - 각 분위수별로 실제 처치효과(ATT)를 계산
    - 예측이 잘 되었다면 10분위 효과 > 1분위 효과
    - 예측이 잘 되지 않았다면 분위수별 효과 차이가 거의 없음
- 분위수별 효과 계산의 핵심은 '모델이 CATE를 잘 정렬했는가'를 검증하는 것.


## 6. 누적 효과 곡선
- 누적 효과 곡선(Cumulative Treatment Effect Curve) : CATE가 높은 순서대로 정렬한 뒤 상위 k% 사용자에게 처치를 적용한다고 가정했을 때 얼마나 효과가 누적되는지 보여주는 곡선
    - 즉, 성능 좋은 타겟팅 모델이 있으면 상위 몇 %에만 처치를 해도 전체 효과의 70~80%가 나온다-는 것을 시각화 한 그래프
- 데이터를 정렬하는 데에 사용한 점수가 실제 CATE의 순서를 잘 반영한다면, 해당 곡선은 매우 높게 시작해서 점차 ATE에 수렴하게 됨
- 반면, 잘못된 모델은 ATE로 빠르게 수렴하거나 지속해서 그 주변에서 변동함
- 누적 효과 곡선은 '단일 숫자로 요약할 수 있다'는 점에서 분위수별 효과 곡선보다 좋음.
    - 단점은 곡선의 시작 부분이 가장 큰 면적을 차지하는데, 바로 이 부분에서 표본 크기가 상대적으로 작기 때문에 불확실성이 가장 큼


## 7. 누적 이득 곡선
- 누적 이득 곡선(Cumulative Gain Curve) : 누적 효과 곡선과 같은 논리를 적용하면서 누적 효과 곡선의 단점을 해결할 수 있는 곡선
- 처치로 얻은 순이득(gain)을 누적해서 보여줌
    - Gain = 효과 x 사용자 수 - 비용
- 즉, ROI가 어디서 최대가 되는지를 확인하는 곡선임
    - 어느 구간까지 타겟팅해야 이득인가.
    - 어느 분위수부터는 처치가 오히려 손해를 일으키는가.


## 8. 목표 변환
- 이질적 효과를 예측할 때 모델이 효과 신호를 잘 포착하게 하기 위해 Y값을 변환해서 학습시키는 방법
- 대표적인 방법은 아래와 같음
    - T-learner / S-learner / X-learner
    - DR-learner (Doubly Robust)
    - R-learner
    - Uplift modeling용 transformed outcome 방법


##9. 예측 모델이 효과 정렬에 좋을 때
- 이질적 처치효과 모델의 목표는 '개별 CATE의 정확한 숫자'를 맞추는 것이 아님
- 실무에서 중요한 것은 효과가 큰 사용자(High Cate)를 상위에, 효과가 작은 사용자(Low CATE)를 하위에 잘 정렬할 수 있는지의 여부.
- 정렬이 잘 된다면
    - 예산이 제한된 상황에서 Top 20%만 타겟팅해도 전체 uplift의 대부분을 가져올 수 있고
    - ROI가 최대화 되기 때문
    - 이러한 이유로 정렬 성능이 중요함
- 어떤 상황에서 모델이 정렬을 잘하는가
    - (1) 한계 수확 체감(Diminishing Marginal Returns)이 있을 때 → 효과 정렬이 훨씬 안정적이다
        - 한계 수확 체감 : 효과가 사용자 특성(X)에 따라 증가할 때 X 증가에 따른 효과 증가폭이 점점 줄어드는 성질
        - 처음 X가 조금 올라갈 땐 효과가 확 튀어오르지만 어느 지점(X*)을 넘으면 효과 증가가 둔화된다.
        - 이러한 경우, 모델이 작은 오차를 내도 정렬이 크게 흔들리지 않음. 또한, 명확한 상위 집단이 존재하며 실무 타겟팅에 매우 유용.
    - (2) 결과가 이진(binary outcome)일 때
        - 개별 CATE 값을 정확히 추정하는 것은 어렵지만 '정렬'은 오히려 쉬워짐
        - 개별 CATE는 원래 정확히 맞출 수 없음. 한 사용자는 T=1 상태 혹은 T=0 상태 중 하나만 경험할 수 있음. Counter-factual이 없으므로.
            - 즉, 정확한 값 추정은 원래 본질적으ㅗㄹ 어려움
        - 그러나, 이진 결과에서는 개별 예측 측면에서 noise가 많더라도 사용자 특성(X)에 따른 패턴은 크게 달라지지 않아 정렬은 훨씬 안정적임
            - 예시
                - 원래 구매 확률이 낮은 X-range와 원래 구매 확률이 높은 X-range를 모델로 구분하는 것은 쉬움
                - 그렇다면, 효과가 낮은 그룹 vs 효과가 높은 그룹-을 rank로 구분하는 것은 상대적으로 쉬워짐
        - 이진결과 일 때 정렬이 쉬운 이유
            - Y가 0 / 1이면 outcome의 변화가 명확히 드러남
                - T=1에서 1이 나오는 비율, T=0에서 1이 나오는 비율. 이 차이가 그룹별로 명확할수록 정렬이 쉬워짐
    - (3) 한계 수확 체감과 이진결과의 결합
        - 사용자의 특성(X)에 따라 한계 수확 체감 구조가 존재하며(효과가 큰 그룹 vs 작은 그룹이 선명해짐) 결과가 이진(구조가 단순해지고 패턴이 뚜렷해짐)이라면 
            → CATE 값 자체를 정확히 맞추기 어렵더라도 정렬은 매우 잘 될 수 있음
        

## 10. 의사결정을 위한 CATE
- CATE를 통해 다음과 같은 실제 액션을 결정해야 함
    - 누구에게 쿠폰을 줄 것인가
    - 누구에게 마케팅 메시지를 발송할 것인가
    - 누구에게 혜택을 줄 것인가
    - 어떤 그룹에 정책을 우선적으로 적용할까
- 또한, 다음을 고려해야 함
    - (1) 비용 고려
        - CATE가 높아도 비용이 더 크면 손해
    - (2) 가용 예산 고려
        - 전체에게 처치할 수 없으면 CATE 높은 사용자부터 top-k 타겟팅
    - (3) 리스크 및 패널티 고려
        - 부정적 효과(CATE < 0)가 있는 군집은 반드시 제외
    - (4) Threshold 선택
        - CATE > 0.05인 사용자만 처치-와 같은 기준을 설정
    - (5) 정책 시뮬레이션
        - 상위 x%에게 처치하면 전체 uplift는 얼마인가?
        - 비용 대비 ROI는?
- 결국, CATE는 더 나은 의사결정을 위해 존재함
