## ATE에서 CATE로
개인화를 위해서는, 이질적 효과를 고려해서 CATE(조건부 평균 처치효과)를 추정하는 것.  
$$E[Y_1 - Y_0 \mid X] \quad \text{or} \quad E[y'(t) \mid X]$$
가정: 모든 대상이 처치에 동일하게 반응하지 않는다.  

이진 처치: 알맞은 대상에만 처치하는게 목표,  
연속형 처치: 각 대상에 맞는 최적의 처치 수준을 파악이 목표  

**예측이 답이 아닌 이유**  
$\frac{\delta y_i}{\delta t_i}$를 구하려하는 것과, $Y$를 구하는 모델은 다르다. 같은 대상을 다른 처치 조건에서 볼 수 없으므로, 전자를 구하려는 특수한 방법을 사용해야하고, 이는 일반적인 예측모델링으로는 해결할 수 없다. 

## 회귀분석으로 CATE 구하기
상황설정: 전국 레스토랑 체인점 운영하는데, 할인을 어느 시기에 하는게 좋을까?  
모든 레스토랑 가격은 일관되고, 요일에 처치하여 날짜와 공변량에 대한 할인의 매출 민감도를 측정하는 모델을 만듦.  
$$\frac{\partial}{\partial t}E[\text{Sales}(t) \mid X]$$
이 모델로 할인 시기와 할인 폭을 결정하고자 함.  

관측할 수 없는 $\frac{\delta Y_i}{\delta T_i}$를 예측해야하는 어려운 상황인거임. $$y_i = \beta_0 +\beta_1t_i+\beta_2X_i+e_i$$ 

같은 선형모델에서 처치에 대해 미분하면 $$\frac{\delta y_i}{\delta t_i}=\beta_1$$
이고, 처치가 무작위 배정되었다면 이 $\beta_1$은 ATE이다.  
즉, **회귀모델로 관측할 수 없는 기울기를 예측할 수 있다**

여기에 처치와 공변량의 상호작용인 $tX$를 모델에 추가: $$y_i = \beta_0 +\beta_1t_i+\beta_2X_i+\beta_3t_iX_i+e_i$$ 
처치에 대해 미분: $$\hat{\frac{\delta y_i}{\delta t_i}}=\hat{\beta_1}+\hat{\beta_3}X_i$$
$\beta_3$: 특성X에 대한 vector coefficient  
$X_i$로 정의된 개별 대상마다 기울기 예상값이 다를것임.  

CATE예측값: (원본데이터에서 처치를 한 단위씩 증가시킨 예측) - (원본데이터로 예측)

그러나, 여기서 질문점: 
1. 이 모델의 성능은 어떻게 평가함?
2. 실제 처치효과가 개별수준에서 관측되지 않으므로, 실제값과 예측값을 비교할수는 없다.

### Quantile (분위수) 효과 곡선
- CATE는 각 개인별 i에서 fitting된 모델로 $\hat{\tau}(Xi​)=\hat{Y}_1​(X_i​)−\hat{Y}_0​(X_i​)$ 를 계산하는 것.
- 그러나 개별 수준에서 관측할 수 없으므로, somehow 그룹화 하여 그룹 내 T=0 샘플, T=1샘플로 ATE를 계산함.  
- 여기서는 $\hat{y}$로 Quantile로 그룹을 나누고, CATE계산하는 방법 설명함.  

처치가 무작위 배정이면, 교란편향을 걱정할 필요는 없다. 즉 ATE 추정은 unbiased.  
> 🔹 하지만 여전히 다음 문제들은 발생할 수 있다  
> - 표본 불균형 → 분산이 커짐
> - missing / selection bias
> - non-compliance
> - 실험 참여 조건이 선택적
> - 표본 효율성 문제  
> 🔹 그래서 IPW, FWL 등을 쓰는 상황  
> 
> | 방법 | 언제 필요? | 이유 | 
> | - |- | - |
> | **IPW** | selection bias, missing, non-response, non-compliance, unequal treatment probabilities | 확률 가중으로 대표성을 복원 |
> | **FWL/회귀 조정** | covariate imbalance, precision 향상 | X를 부분 잔차로 제거하여 분산 축소(효율성 증가) |
> | **둘 다 필요 없는 경우** | 완전무작위 실험 + 대규모 표본 + missing 없음 | 단순 평균차이가 최적 |

- 여기서는 Quantile로 그룹을 나누고, CATE계산하는 방법  
  1. CATE 모델이 각 샘플마다 예측값 $\hat{y}_i$ 생성
  2. $\hat{y}_i$ 기준으로 전체 샘플을 분위수 bin으로 나누기 (Q1~Q10)
  3. 각 $bin_k$ 내부에서 $ATE_k$ 계산
    - 단순선형회귀분석으로 회귀계수 추정도 가능: $$\hat{\beta_i} = \frac{\sum(t_i - \bar{t})y_i}{\sum(t_i - \bar{t})^2}$$   
  4. $(bin_k, ATE_k)$ 점들을 이어서 
    quantile effect curve 생성

이 방법은 모델 성능을 하나의 수치로 요약해주진 않음.  
아래 cumulative effect curve는 그렇게 해줌.  
### cumulative effect curve (누적 효과 곡선)
이번에는 그룹별 효과 추정이 아니고, 한 그룹을 다른 그룹위에 누적해서 진행.  
1. 보통 CATE모델의 점수로 데이터를 점수순으로 정렬  
2. 상위 1% 효과 추정
3. 1% 추가하여 상위 2% 효과 추정
4. ... 계속 진행해서 누적 표본에 따른 효과 곡선 그림.  
  - 데이터 정렬에 사용한 점수가 실제 CATE순서를 잘 반영한다는 가정하에 진행한 것.  
    - 만약 그렇다면, 이 곡선은 매우 높았다가 점차 ATE에 수렴
    - 잘못된 모델은 ATE로 빠르게 수렴하거나 ATE근처에서 진동
5. 곡선과 ATE사이 면적으로 서로 다른 모델 비교 가능
  - 면적 클수록 더 좋은 모델
  - 단점: 곡선 시작 부분이 가장 큰 면적인데, 이 부분에서 샘플이 작아서 불확실성이 커짐
    - 단점 해결법: 다음에 나올 cumulative gain curve

**cumulative gain curve(누적 이득 곡선)**  
각 데이터 포인트에 누적 표본 $N_{cum}/N$을 곱하여 그린 곡선  

* 사용시 주의점
  - 이 값들은 추정값일 뿐, 모델링에 따라 결과가 틀려질 수 있다.
  - CATE순서에만 초점을 둔 것. CATE에 대한 편향된 추정량이 있어도 나타나지 않음
    - 정확한 CATE추정이 목적이면 이 곡선은 오해를 부를 수 있다.
    - CATE 정확한 추정법은 아직 연구중이라고 함.. ㄷㄷ
  - confounding 없는 데이터라는 가정 하에 실시함
    - IPW 등으로 데이터 편향제거 가능하긴함

예측모델에는 RMSE같은 요약 지표가 있지만, CATE 인과모델링에는 이런 지표는 없다고 함. target transformation이라는 개념이 있긴 함.

## target transformation (목표 변환)
실제 처치효과를 관측할수는 없지만, 기댓값에서 실제 처치효과를 근사하는 목표변수를 다음과 같이 만들 수 있음.  

$$Y_i^* =  \frac{(Y_i - \hat{\mu}_y(X_i))(T_i - \hat{\mu}_t(X_i))}{(T_i - \hat{\mu}_t(X_i))^2} = \frac{(Y_i - \hat{\mu}_y(X_i))}{(T_i - \hat{\mu}_t(X_i))}$$

- $\mu_y$: 결과에 대한 모델 $\mu_t$: 처치에 대한 모델  
- $E[Y^*] = \tau_i$, 즉 개별수준의 실제 처치효과.
  - 증명?
- 이 목표는 처치의 평균값 근처에서 분모가 0 근처라 노이즈가 매우 커짐.
  - 이 지점에 중요도를 부여하는 가중치 적용 가능, 다음 장에서 자세히 나옴
- CATE에 대한 모델이 개별수준효과 $\tau_i$ 예측에 효과적이라면, 이 목표에 대한 모델의 예측 MSE는 작아야 함.
  - 이 값이랑 모델 예측 결과가 비슷해야함
- 결과가 효과와 상관관계가 있을 때만, Y를 예측하는 것이 처치효과의 순서정렬이나 개별수준 효과 $\tau_i$를 예측하는데 효과적임
  - 처치 반응 함수가 비선형일 때가 일반적임

**예측 모델이 효과 정렬에 좋을 때**  
- 처치 반응 함수가 비선형이거나 결과가 점진적으로 감소하는 경우, 예측모델은 CATE순서를 잘 정렬할 수 있음
- 그러나 대체로 잡음이 많아서, 종종 결과 예측이 CATE예측보다 좋을 수 있다.
  - [Fernandez-Loria, C. & Provost. F. (2019)](https://jmlr.org/papers/volume23/19-480/19-480.pdf)


## 의사결정을 위한 CATE
1. 이진처치
  - 누가 처치에 긍정적으로 반응하는지 확인
  - 처치 무한정: CATE양수인 모든 사람에게 처치
    - CATE예측 모델이 없지만, 순서 정하는 모델이 있다: model quantile 효과 곡선 활용해서 효과가 양인 지점의 대상에게 처치
  - 처치 비 무한정: 추가규칙 설정
    - 처치에 긍정적이면서도 CATE가 높은 대상에게 처치

2. 처치가 연속형 / 정렬된 경우
  - 누구에게 어느정도의 처치를 줄 지 결정
  - 문제/도메인 별로 고유한 처치 반응 함수가 있어서 이를 따르기
  - 숨겨진 비용 (가격 상승하는 요인인 줄 알았는데, 고객 피로/짜증이 올라서 오히려 가격 하락)이 있는지 신중히 고려
