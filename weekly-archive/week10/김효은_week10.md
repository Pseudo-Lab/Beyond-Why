## * 학습 내용 요약
### CATE(Conditional ATE) 추정으로 할 수 있는 일
- **ATE 추정으로 할 수 있는 결정: 처치 시행 여부에 대한 결정** (전체 모집단 대상)
    - ATE: E[Y1-Y0], E[y’(t)]
- **CATE 추정으로 할 수 있는 결정: 처치 시행 집단에 대한 결정**
    - CATE: E[Y1-Y0|X], E[y’(t)|X]

### 회귀분석을 이용해 CATE 추정하는 방법
- (1) 처치와 공변량 뿐만 아니라 **처치와 공변량의 상호작용항을 추가하여 회귀모델 적합**
- (2) 원본 데이터를 활용하여 Y 예측
- (3) 원본 데이터에서 처치를 한 단위씩 증가시킨 데이터를 활용하여 Y 예측
- (4) (2), (3) 두 예측값의 차이가 CATE 예측값

```python
import numpy as np
import pandas as pd

import statsmodels.formula.api as smf

# 3년동안 전국적으로 실험을 진행하여, 6개의 체인점에서 "무작위로 할인(T) 제공"
# sales: 매출액(Y)
# discounts: 할인율(T) (0, 5, 10, 15, 20, 25, 30, 35, 40, 45)
df = pd.read_csv("/content/drive/MyDrive/인과추론/data/daily_restaurant_sales.csv")

X = ["C(month)", "C(weekday)", "is_holiday", "competitors_price"]
model = smf.ols(f"sales ~ discounts*({'+'.join(X)})", data=df).fit()

ols_cate_pred = (
    model.predict(df.assign(discounts=df["discounts"] + 1)) # 원본데이터에서 처치 1단위 증가했을 때 Y예측
    - model.predict(df) # 원본데이터에 대한 Y 예측
)
```

### CATE 평가 방법
- **평가 한계**
    - 개인마다 처치 / 미처치를 모두 관측할 수 없기 때문에 ITE 관측 불가
    - 따라서 그룹 수준의 지표로 개별 대상의 처치 효과를 판단
- **평가 방법**
    - 1) 데이터를 학습데이터와 평가데이터로 나눔
    - 2) 학습데이터를 이용해 CATE 예측하는 모델 생성
    - 3) 평가데이터를 이용해 CATE 예측값 생성
    - 4) 모델분위수에 따른 효과그래프 / 누적효과곡선 / 누적이득곡선 그려 평가
        - 세 방법 모두 CATE 값이 얼마나 정확한지 평가하는 방법은 아니고 (← 아직 연구 중인 분야)
        - **추정된 CATE의 순서와 실제 CATE의 순서가 얼마나 일치하는지 평가하는 방법임**
- **평가 결과 해석 시 주의할 점**
    - 1) 위 방법으로 평가했을 때 가장 좋은 모델이라 하더라도 곡선 위의 값은 추정값이며 참값은 아님을 명심
        - 회귀계수 추정값은 T와 Y 사이의 관계가 올바르게 정의되었는지에 따라 달라짐
        - 실제 관계가 로그함수 형태인데 선형으로 추정하면 잘못된 결과 나올 수 있음
    - 2) 위 방법으로는 추정된 CATE의 순서가 올바른지에 대해서만 확인 가능 (값에 대해서는 평가 X)
        - 처치의 우선순위 결정하는데에는 활용할 수 있지만
        - 처치효과를 사전확인하는데에는 도움되지 않음
    - 3) 교란이 없는 데이터가 필요함
        - 편향이 있다면 추정하는 효과가 잘못될 수 있음
        - 처치가 무작위 배정되지 않았다면 IPW의 직교화 등을 사용하여 편향 제거 후 평가 기법 사용 가능
        - 다만 필자는 이 방법에 대해서는 회의적임

```python
df_train = df.query("day <= '2017-12-31'") # 학습셋
df_test = df.query("day >= '2018-01-01'")  # 평가셋

X = ["C(month)", "C(weekday)", "is_holiday", "competitors_price"]

model = smf.ols(f"sales ~ discounts*({'+'.join(X)})", data=df_train).fit()

cate_pred = (
    model.predict(df_test.assign(discounts = df_test["discounts"] + 1))
    - model.predict(df_test)
)
```

### 평가 방법 1: **모델 분위수에 따른 효과 그래프**
- 방법 
  - 개별 개체마다 추정된 CATE를 분위수에 따라 나눈 뒤
  - 해당 그룹별로 ATE를 추정하여
  - CATE 분위수 대표값과 그룹별 추정효과(ATE)가 얼마나 정비례하는지 시각적으로 비교
- 해석
  - CATE 분위수별 중위수 기준 랭킹과 그룹별 ATE 추정 랭킹 유사하면 CATE 예측이 실제 효과 순서를 매긴다고 해석
  - 각 분위수의 중간값과 ATE 추정값이 유사한 것을 보아 CATE 추정값 정확하다고 해석
  - 그래프가 계단 모양이라면 CATE 순서 정렬이 잘 되었다고 판단
- 장점
  - 시각적으로 추정된 CATE와 구간별 ATE의 관계성 확인 가능
- 단점
  - 두 개 이상의 모델 성능을 수치적으로 비교하기 어려움

### **평가 방법 2: 누적 효과 곡선 (Cumulative Effect Curve)**
- 방법
  - (기본 아이디어) 그룹별로 효과를 추정하지 않고 한 그룹을 다른 그룹 위에 누적하는 형태로 진행
  - ㄴ (1) 데이터를 점수 순서대로 정렬 (보통 CATE 점수 기준 정렬)
  - ㄴ (2) 해당 정렬에 따라 상위 1%의 효과 추정
  - ㄴ (3) 다음에는 1% 추가하여 상위 2%의 효과 추정
  - ㄴ (4) 그 후 1% 추가하여 상위 3%의 효과 계산하는 식으로 계속 진행
  - ㄴ (5) 결과적으로 누적 표본에 따른 효과 곡선 생성
- 해석
  - 1) 데이터 정렬 시 사용한 점수가 실제 CATE 순서를 잘 반영한다면: 해당 곡선은 높게 시작해서 점차 ATE에 수렴하는 형태
  - 2) 데이터 정렬 시 사용한 점수가 실제 CATE 순서를 잘 반영하지 않는다면: ATE로 따르게 수렴하거나 ATE 주변에서 변동하는 형태
- 장점
  - 곡선과 ATE 직선 사이의 면적을 계산하여 수치적 비교 가능 (→ 분위수 그래프 단점 개선)
- 단점
  - 곡선의 시작 부분에서는 표본크기가 상대적으로 작은데 비해 면적이 커 불확실성 큼 (→ 누적이득곡선에서 완화)

### **평가 방법 3: 누적 이득 곡선 (Cumulative Gain Curve)**
- 방법
  - 누적 효과 곡선과 같은 논리를 적용하지만
  - 각 데이터 포인트에 누적 표본 N_cum / N을 곱함
  - 각 구간에서 구한 ATE에 대해 전체 기준 ATE를 빼는 과정 추가하여 정규화도 가능
- 해석
  - 곡선과 ATE 나타내는 선 사이의 면적이 가장 큰 모델일수록 실제 CATE 순서를 잘 반영하는 모델
- 장점
  - 곡선과 ATE 직선 사이의 면적(AUC)을 계산하여 수치적 비교 가능
  - 곡선의 시작 부분에서는 표본크기에 따라 가중치 부여하여 불확실성 줄임

### 평가 방법 4: 목표 변환
- 실제 처치효과를 근사하는 값과 예측된 CATE 값의 **MSE** 구해보는 것

$$
Y_{i}^{*}=\frac{Y_{i}-\hat{\mu_{y}}(X_{i})}{T_{i}-\hat{\mu_{t}}(X_{i})}
$$

### 예측 모델이 효과 정렬에 좋을 때
- **효과와 결과 사이 상관관계가 있을 때만 Y 예측이 순서를 잘 나타내는데 유용함**
    - 예를 들어, 매출이 높은 날 사람들이 할인에 더 민감하게 반응한다면
    - Y 예측하는 모델은 T가 Y에 미치는 효과의 순서도 잘 예측할 것임
- 사례 1. 한계 수확 체함
    - 처치 - 반응 함수가 오목한 형태
    - Y 예측 모델이 CATE를 잘 정렬할 수 있는 이유는 결과가 높을수록 효과가 낮기 때문
    - 따라서 Y를 예측하는 모델 예측값의 역순으로 정렬하면 CATE 순서 정렬 가능함


### 의사 결정을 위한 CATE
- 이진 처치
    - 모델 분위수별로 데이터를 나누고 각 분위수에서 처치효과 추정 후
    - 효과가 여전히 양의 값을 보이는 지점까지의 모든 대상에게 처치
- 연속형 처치
    - 최적화해야 할 고유의 처치 반응 함수 존재
    - 레스토랑 체인에서 얼마나 할인을 제공할지 결정하는 문제 사례 제시
        - 고객의 가격에 대한 수요 반응도에 따라 이익을 극대화하는 가격 달라짐
        - 수요 = f(가격)
        - 총 매출 = 수요 * 가격
        - 총 비용 = 수요 * 단가
        - 총 이익 = 총 매출 - 총 비용
