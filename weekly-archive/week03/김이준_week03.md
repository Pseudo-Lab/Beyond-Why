## 📚 학습 내용 요약
  - 평균 처치효과
  ATE = E[Y(1) - Y(0)] = E[Y(1)] - E[Y(0)]
  정책 결정에 가장 유용한 지표
  - 처치군 평균 처치효과
  ATT = E[Y(1) - Y(0)|T = 1]
  기존 고객 대상 서비스 개선 시 유용
  - 조건부 평균 처치효과
  CATE(x) = E[Y(1) - Y(0)|X = x]
  개인화 전략 수립에 핵심
  - 편향 (Bias)의 종류와 대응법
    - 선택 편향
      처치군과 대조군의 기본 특성이 다를 때 발생
      효과가 과대 추정 우려
    - 교란 편향
      처치와 결과에 모두 영향을 미치는 제3의 변수 존재
    - 충돌자 편향
      처치와 결과의 공통 결과 변수로 조건화할 때 발생
      eg. 비만 치료제 택 1
    - 생존자 편향
      특정 조건을 만족한 개체만 관측될 때 발생
      eg. 1등만 기억하는 ~ 세상의 편향
  - 식별
    관측 불가능한 do(T=t) 연산을 관측 가능한 데이터로 표현하는 과정
  - 무작위 실험
    완전 무작위화
      # 각 개체를 독립적으로 처치군에 배정
      treatment = np.random.binomial(1, 0.5, n)
    블록 무작위화 (Block Randomization)
      # 특정 특성별로 층화 후 무작위화
      for group in groups:
      treatment[group] = np.random.permutation([0,1] * (len(group)//2))
    클러스터 무작위화 (Cluster Randomization)
      개별이 아닌 집단 단위로 무작위 배정으로 unity 단위 용도 (학교,지역 등)
    무작위화가 편향을 제거하는 원리
      무작위 배정 시:
      E[Y(0)|T=1] = E[Y(0)|T=0] = E[Y(0)]
      E[Y(1)|T=1] = E[Y(1)|T=0] = E[Y(1)]

      E[Y|T=1] - E[Y|T=0] = E[Y(1)] - E[Y(0)] = ATE
  - A/B 테스트의 실무 적용    
    - 가설 수립
      종속,독립 변수 정의 및 효과 크기 설정(실무적으로 의미있는 최소 차이)
    - 성공 지표 정의
      주요 지표 : KPI
      보조 지표 : 부작용 모니터링
      가드레일 지표 :  시스템 안정성
    - 표본 크기 계산
      n = (Z_{α/2} + Z_β)² × (σ₁² + σ₂²) / δ²
        - Z_{α/2}: 유의수준에 대한 임계값
        - Z_β: 검정력에 대한 임계값  
        - σ₁², σ₂²: 각 그룹의 분산
        - δ: 감지하고자 하는 효과 크기
    - 무작위 배정
      용자 ID 기반 해시 함수 활용
      일관성 보장 (동일 사용자는 항상 같은 그룹)
      균형 확인 (그룹간 크기 및 특성 비교)

  - 이상적인 실험의 조건
    - 내적타당성
        무작위 배정: 선택 편향 제거
        충분한 표본 크기: 통계적 검정력 확보
        일관된 처치: 구현 충실도 보장
        균형된 그룹: 공변량 분포 유사성
    - 외적 타당성
        대표성: 표본이 모집단을 잘 대표
        일반화 가능성: 다른 상황/시점에서도 유효
        생태학적 타당성: 실제 환경과 유사한 조건

  - 실무적 함의
      작은 표본의 위험성: 우연의 영향이 과대 평가됨
      표본 크기의 중요성: n이 4배 증가하면 SE는 절반으로 감소
      다중 비교 문제: 여러 지표를 동시에 분석할 때 우연히 유의한 결과 발견 가능성
  - 검정력에 영향을 미치는 요인
      효과 크기 (Effect Size): 클수록 검정력 증가
      표본 크기 (Sample Size): 클수록 검정력 증가
      유의수준 (α): 클수록 검정력 증가 (하지만 1종 오류 증가)
      측정 오차: 적을수록 검정력 증가
