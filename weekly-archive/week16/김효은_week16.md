### * 지역 실험 설계에서 어려운 점
- **(1) 지역 실험을 진행할 도시를 정의해야 함**
    - 일부 지역에 대한 처치를 통해 전체 시장에서 동일하게 처치했을 때 결과를 예상하고 싶음
    - 따라서 전체 시장을 대표할 수 있는 지역을 선택하는 것이 필요함
- **(2) 지역 실험을 진행할 도시의 수도 정의해야 함**
    - 하지만 지역 실험에 필요한 도시의 수를 판단하는 것도 쉽지 않음
    - n = (16 * sigma^2) / (delta^2)
    - 아래 데이터 기반으로 5% 효과를 탐지하려면 약 4만개의 도시 필요

```python
detectable_diff = df["app_download"].mean()*0.05
variance = df.groupby("city")["app_download"].mean().var()

print((16 * variance) / detectable_diff**2) # 36662
```

- **(3) 지역 실험 결과를 어떻게 해석할지 미리 염두에 두어야 함**
    - 처치의 전반적인 효과를 알고 싶은 상황에서는 ATT만 아는 것으로는 충분치 않음
    - (참고) ATT = Average Treatment Effect on the Treated = E[Y(1) - Y(0) | D=1]
    - (참고) ATE = Average Treatment Effect = E[Y(1) - Y(0)]

### * 지역실험 설계: 어떤 지역을 대상으로 지역실험을 진행할 것인가?
- 요약
    - 실험대상이 적은 경우 최적의 실험군을 선정하는 것이 중요함 (예: 지역실험)
    - 이번 절에서 통제집단합성법을 이용하여 실험군 설계 방법에 대해 다룸
- 지금까지 우리는,
    - 통제집단합성법을 활용하여 **실험군의 결과를 잘 근사하는 가상의 대조군**을 찾았음
    - 이제부터는 **모든 실험 대상의 평균 결과를 잘 근사하는 가상의 실험군**을 찾아야 함 (=어떤 지역에서 실험할지)
- 그렇다면 우리는,
    - 실험 대상 중 어떤 일부는 실험군, 다른 일부는 대조군으로 선정해야 하는데
    - **두 그룹(실험군, 대조군)의 가중평균이 시장 평균에 근접하도록 선정해야 함**
    - 수식으로 표현하면 아래와 같음
        - (1) 실험군과 대조군에 대해 절편이동 허용 (alpha_0, beta_0)
        - (2) 가중치의 합은 1이여야 하며 음수가 아니어야 함
        - (3) 한 도시가 실험군과 대조군에 동시에 속할 수 없음
        - (4) 실험군의 최대 도시수 m개 제안
    - 반드시 최적의 실험군/대조군을 찾을 필요는 없음 (충분히 적절한 도시 그룹을 찾아도 됨. 이것은 쉬움.)

- 어떻게 하면 되는가? (사례) 무작위로 실험군 선택하기
    - 랜덤하게 아래 과정을 계속 수행 후 최종적으로 손실값이 가장 적었을 때의 (대조군, 실험군) 채택
        1. 무작위로 실험군 도시 M개 선택하기
        2. 모델 적합하여 손실함수 값 구하기 (M개 도시로 전체 평균값 예측했을 때 오차)
        3. 가중치 일정 수준 이상인 도시 N개를 를 최종 실험군 도시로 선정
        4. 실험군으로 선정된 도시 N개를 제외한 나머지 도시 대상으로 무작위로 대조군 도시 M개 선택
        5. 모델 적합하여 손실함수 값 구하기
        6. 2번과 5번 단계에서 구한 손실의 합을 전체 손실값으로 정의
    - 랜덤하게 탐색하는 방법 말고도 사용 가능함
    - 대부분의 손실은 실험군에서 발생함 (실험군의 개수가 적을수록 이 문제는 더 심해짐)

### * 스위치백 실험
- **스위치백 실험(switchback experiment) 정의**
    - 한 대상에 대해 여러번 처치를 가하며 전후 비교를 하는 방법
- **스위치백 실험이 필요한 경우?**
    - 실험 대상이 1개 혹은 매우 적은 경우
    - (예) 1개 지역에서만 서비스를 하고 있어서 지역 실험이 어려운 경우
- **스위치백 실험이 가능한 경우?**
    - 처치의 효과가 금방 사라지는 경우 (=이월효과의 차수가 작은 경우)
    - 즉, 처치가 끝난 후에도 장기간에 걸쳐 지속되지 않아야 함
- 스위치백 실험 기반 추정
- (1) 잠재적 결과 → 벡터 형태
    - 처치효과가 이후 시간까지 영향을 준다는 점을 고려하면 **잠재적 결과는 벡터의 형태로 정의**되어야 함
    - 가정 1. 잠재적 결과는 과거와 현재의 처치에만 의존하며, **미래의 처치에는 영향을 받지 않음**
    - 가정 2. 이월 기간 m의 크기를 안다면 아래와 같이 추가 단순화 가능 (m=2 가정)     

$$ Y_{t}(D)=Y_{t}([d_{0}, d_{1}, ..., d_{t}]) \text{ (가정 1)} $$
$$ Y_{t}(D)=Y_{t}([d_{t-2}, d_{t-1}, d_{t}]) \text{ (가정 2)} $$
    
- (2) 전체 처치효과 → 항상 처치를 받는 상태와 항상 처치를 받지 않는 상태의 차이
    - 첫 번째 항 = 항상 처치를 받는 상태
    - 두 번째 항 = 항상 처치를 받지 않는 상태
    - 처치효과 = 두 개 상태의 차이

$$
\tau_{m}=E[Y_{t}(1_{t-m}, ..., 1_{t}])-E[Y_{t}(0_{t-m}, ..., 0_{t}])
$$
        

- (3) 이월 효과 차수 측정
    - 가정: 시차의 효과가 가산적임(additivd)
    - 방법:
        - ① 도메인지식을 활용하여 이월효과 차수의 상한선 설정
        - ② 회귀 모델 적합하기
        - ③ 추정값의 크기와 유의성 살펴보기 (어느 차수까지 유의한지 살펴봄)

$$
Y_{t}=f(d_{t}, d_{t-1}, d_{t-2})=\alpha+d_{t}+d_{t-1}+d_{t-2}+e_{t}
$$

### * 스위치백 실험: 모델 기반 추정(OLS)

$$
\hat{\tau}_m = \sum_{l=0}^{lags}{\hat{d}_{t-l}}
$$

```python
df = pd.read_csv("../data/sb_exp_every.csv")
df_lags = df.assign(**{f"d_l{l}": df["d"].shift(l) for l in range(7)})

model = smf.ols(
    formula=f"delivery_time ~ {"+".join(["d_l{}".format(l) for l in range(7)])}",
    data=df_lags
).fit()

print(model.summary().tables[1])

"""
- 2개 기간에 걸친 이월효과가 있음
==============================================================================
                 coef    std err          t      P>|t|      [0.025      0.975]
------------------------------------------------------------------------------
Intercept      9.3270      0.461     20.246      0.000       8.414      10.240
d_l0          -2.9645      0.335     -8.843      0.000      -3.629      -2.300
d_l1          -1.8861      0.339     -5.560      0.000      -2.559      -1.213
d_l2          -1.0013      0.340     -2.943      0.004      -1.676      -0.327
d_l3           0.2594      0.341      0.762      0.448      -0.416       0.935
d_l4           0.1431      0.340      0.421      0.675      -0.531       0.817
d_l5           0.1388      0.340      0.408      0.684      -0.536       0.813
d_l6           0.5588      0.336      1.662      0.099      -0.108       1.225
==============================================================================
"""

# 시차 3 설정
tau_m_hat = model.params[1:4].sum()
se_tau_m_hat = np.sqrt((model.bse[1:4]**2).sum())

print("tau_m:", tau_m_hat)
print("se_tau_m:", se_tau_m_hat)
print("95% CI:", tau_m_hat - 1.96*se_tau_m_hat, tau_m_hat + 1.96*se_tau_m_hat)

# tau_m: -5.851856895442302
# se_tau_m: 0.5858409571019754
# 95% CI: -7.000105171362174 -4.703608619522431

# 시차 6 설정 (추정량 분산 커짐)
tau_m_hat = model.params[1:].sum()
se_tau_m_hat = np.sqrt((model.bse[1:]**2).sum())

print("tau_m:", tau_m_hat)
print("se_tau_m:", se_tau_m_hat)
print("95% CI:", tau_m_hat - 1.96*se_tau_m_hat, tau_m_hat + 1.96*se_tau_m_hat)

# tau_m: -4.751686115272046
# se_tau_m: 0.8964450320829267
# 95% CI: -6.508718378154583 -2.99465385238951
```

### * 스위치백 실험: 디자인 기반 추정(IPW)
- **문제 제기**
    - 앞서 소개한 과정은 잠재적 결과 **Y_t(D) 모델 설정이 정확해야 한다는 가정**을 전제로 함
    - 그러나 지금 다루고 있는 시계열 데이터에서 쉬운 작업이 아님
    - 한 가지 대안은 처치가 어떻게 배정되었는지 알면 **IPW 방법을 통해 처치효과를 추정**하는 것
    - ⇒ 불확실한 결과 예측 모델이 아닌 실험 처치 배정 방식에 집중 (그래서 디자인 기반의 추정이라고 표현)
- **IPW 추정량 구하는 방법**

$$
\hat{\tau}=\frac{1}{T-m}\sum_{t=m+1}^{T}\{Y_{t}\{\frac{1(D_{t-m:t}=1)}{P(D_{t-m:t}=1)}-\frac{1(D_{t-m:t}=0)}{P(D_{t-m:t}=0)}\}\}
$$

- IPW 추정량 vs. OLS 기반 효과 추정량
    - 두 방법 모두 편향되지는 않았으나
    - **OLS 기반 추정량의 분포 대비 IPW 추정량의 분포가 더 넓게 퍼져있음 (분산 큼)**
- (참고) P(D_{t:m:t}=1), P(D_{t:m:t}=0)의 경우에는 랜덤화 시점과 시퀀스에서의 위치에 따라 달라짐
    - (1) 매 시점마다 처치 배정 랜덤화
        - [1, 1, 1, 1, 1, 1] 수열에서와 같이 세 번 연속 같은 처치를 관측할 확률은 (처치 배정 확률: 0.5)
        - ⇒ [na, na, 0.5^3, 0.5^3, 0.5^3, 0.5^3]
    - (2) 세 번의 기간마다 처치 랜덤화 (=첫 번째 랜덤화 결과 3번의 기간동안 지속됨)
        - [1, 1, 1, 1, 1, 1] 수열에서와 같이 세 번 연속 같은 처치를 관측할 확률은 (처치 배정 확률: 0.5)
        - ⇒ [na, na, 0.5, 0.5^2, 0.5^2, 0.5]

### * 스위치백 실험: IPW 기반 추정량의 분산을 줄이는 방법
- **문제 제기**
    - 추정 관점에서 큰 분산은 바람직하지 않음
    - IPW 추정량을 사용하여 분산을 줄일 수 있는 실험을 설계하는 것 필요함
- **아이데이션**
    - IPW 추정량 공식을 보면 m+1개의 연속적인 처치가 동일한 시퀀스만 유지
    - 따라서 더 많은 데이터를 사용하고 싶다면 연속적으로 동일한 처치를 더 많이 확보하면 됨
- **해결 방법**
    - m+1 기간마다 랜덤화 하는 것
    - T* = {1, 2m+1, 3m+1, …, (n-2)m+1} (m=이월효과 차수, n=T*m (최소 5 이상))
- **한계점**
    - 최적 설계를 사용할 때 얻을 수 있는 분산 감소가
    - 모델 가정을 하고 OLS를 사용하여 얻을 수 있는 분산 감소보다는 작음
    - (그럼에도 불구하고 IPW 알아두는 이유는 편향이 없기 때문임)
