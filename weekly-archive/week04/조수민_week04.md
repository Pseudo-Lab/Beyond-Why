
# Chapter 3. 그래프 인과모델 (Graphical Causal Models)

---

## 인과관계 개념 & DAG 개요

- **DAG (Directed Acyclic Graph)**:  
  변수 간의 인과관계를 화살표로 나타내며, 순환(cycle)이 없는 구조.  


- 인과추론에서 가장 중요한 것은 **무엇을 통제**(**조건부**로 두어)야 인과효과를 식별할 수 있는가.  
  DAG는 이 의사결정을 **시각적으로 표현**한다.


---

## 기본 그래프 구조 (Three Basic Patterns)

### (1) 사슬 구조 (Chain structure / Mediator)
```
T → M → Y
```
- **M (Mediator)**: 매개자, 처치(T)가 결과(Y)에 영향을 미치는 중간 경로에 있는 변수.  
- **의미:**  
  - T와 Y는 기본적으로 **연관(associated)**되어 있다.  
  - M을 **조건부로 설정(conditioning)**하면, T와 Y의 관계가 **차단(d-separated)**된다.  
  - 즉, 매개자를 통제하면 간접효과는 사라지고, **직접효과(direct effect)**만 남는다.

**예시:**  
- 인과추론 공부(T)가 문제 해결력(M)을 높이고, 문제 해결력이 승진(Y)에 영향을 준다.  
- 문제 해결력을 동일하게 고정(M conditioning)하면, 인과추론 공부 여부(T)는 승진(Y)에 더 이상 추가 정보를 주지 않는다.  


---

### (2) 분기 구조 (Fork structure / Confounder)
```
T ← C → Y
```
- **C (Confounder):** 공통 원인, 처치와 결과에 모두 영향을 주는 변수.  
- **의미:**  
  - C로 인해 T와 Y가 **비인과적 연관(non-causal association)**을 가질 수 있다.  
  - 따라서 **C를 조건부로 두면**, T와 Y의 비인과 경로가 **차단(blocked)**된다.

**예시:**  
- 통계(C)를 잘하면 인과추론(T)도 잘하고, 머신러닝(Y)도 잘한다.  
- Confounder를 통제하지 않으면, 인과추론과 머신러닝은 **잘못된 연관성**을 가진 것처럼 보인다.


---

### (3) 충돌부 구조 (Collider Common Effect)
```
T → Z ← Y
```
- **Z (Collider):** 공통 효과, 독립된 두 원인의 결과.  
- **의미:**  
  - 기본적으로 T와 Y는 **독립(independent)**이다.  
  - 하지만 Z를 **조건부로 두면**, 오히려 T와 Y가 **연관되어 버린다** → **선택편향(selection bias)**, 혹은 **거짓 역상관관계**가 관찰될 수 있음음.

**예시:**  
- 옷을 잘 입으면(T) 인기가 많다(Z), 그리고 말을 잘 하면(Y) 인기가 많다 (Z) 
  - 옷 잘 입는거(T)랑 말 잘 하는거(Y)는 사실 상관이 없음. 하지만 Z를 넘겨서 보면 이 둘 사이의 상관관계가 있는 것 처럼 보여짐

**요약:**  

> 충돌부(Colliders)를 충분히 규명하지 않으면 T-Y 직접 관계로 오해할 수 있음

## 인과효과의 식별 (Identification)

- **식별**(**Identification**)이란?  
  인과 그래프에서 처치(T)와 결과(Y) 사이의 **비인과 경로(backdoor path)**를 차단하여, **진짜 인과성**만 남기는 과정.


---
## 교란 편향 (Confounding Bias)

- **정의:** T와 Y가 **공통원인(confounder)**을 공유하여 생기는 비인과적 연관성.  
- **해결:** 교란변수(C)를 직접 또는 대리변수(proxy variable)로 통제.

**대리변수(proxy variable) 예시:**  
-          지능(U)
          ↙      ↘
       교육(T) → 임금(Y) 
   
- 교란변수가 Treatment와 Outcome에 둘 다 영향을 미침
- 모호한 변수이기에 직접 통제(예, 지능은 똑같지만 교육 수준이 다른 샘플들을 비교)는 힘듦

  - 이 때, U를 상당 부분 설명하는 대리 변수(Proxy)를 변수로 포함시키기: 예 지능: IQ, 시험성적 등 측정 가능한 변수            
                   


---

## 선택 편향 (Selection Bias)

- **정의:** 공통효과(colliders)나 매개자(mediators)에 조건을 둘 때 발생하는 편향.  
- **발생 구조:** `T → Z ← Y` 형태에서 Z 또는 Z의 자식을 조건부로 둘 때(즉, Z의 전체 조건이 아닌 일부분만 관찰할 때).

### 예시  — 생존자만 남은 데이터 (Survivorship bias)
- 대출 금액(T) → 부도(Y)  
- 생존한 고객만 2년 차에 관측 → 결과가 선택을 유발.  
- 따라서 연도별 부도율보다는 **누적 부도율 P(Default | year ≤ 2)**를 보는 것이 안전하다.

- **해결\보정**: PSM, ISW 등?

## 나가며... (요약)

| 구조 | 영어 용어 | 조건부 효과 | 인과해석 |
|------|------------|--------------|-----------|
| `T → M → Y` | Mediator | M을 통제하면 관계 차단 | 직접효과만 남음 |
| `T ← C → Y` | Confounder | C를 통제해야 함 | 비인과 경로 차단 |
| `T → Z ← Y` | Collider | Z를 통제하면 안 됨 | 선택편향 발생 |
