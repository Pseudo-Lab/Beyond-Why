## * 학습 내용 요약
### 회귀분석은 인과추론의 핵심
- 회귀분석은 아래와 같이 다양한 방법론의 주요 구성 요소
- ① 패널데이터 방법 (이중차분법(DID; Difference In Differences), 이원고정효과(TWFE; Two Way Fixed Effects))
- ② 머신러닝 방법 (이중/편향 제거 머신러닝)
- ③ 식별 기법 (도구변수, 불연속설계)

### 인과추정량 구할 때 회귀분석을 활용한다면, 차원의 저주 완화 가능
- 배경: 교란효과가 있을 때 아래와 같은 보정공식을 사용하여 인과추정량 구함
    - ATE = E{E[Y|T=1, X=x] - E[Y|T=0, X=x])P(X=x)}
- 문제: 특성 X의 개수가 많을수록 ATE를 추정하기 위해 필요한 데이터의 양 급증 (차원의 저주)
- 완화: 회귀분석을 사용하면 E[Y|T, X]를 특정 함수형태로 가정하기 때문에 예측한 값을 활용하여 추정량 구할 수 있음
    - 물론, 예측 값을 활용하기 때문에 예측이 정확하지 않으면 인과추정량도 정확하지 않게 됨

### 실험 데이터에서 단순선형회귀 이용하여 ATE 구하기
- ① A/B 테스트 수행 후 처치변수에 따른 결과변수의 평균차 **= ATE**
- ② A/B 테스트 수행 후 처치변수를 설명변수, 결과변수를 반응변수로 설정 후 회귀분석 진행 시 **처치변수에 대한 회귀계수 = ATE**
    - 1) 처치가 이산형 변수일 때 회귀계수 해석: 처치를 가했을 때 결과변수의 결과변수 기댓값 변화량
    - 2) 처치가 연속형 변수일 때 회귀계수 해석: 처치가 1만큼 증가할 때 결과변수의 기댓값 변화량

### 비실험 데이터에서 다중선형회귀 이용하여 교란요인 보정하여 ATE 구하기
- **회귀분석 모델 설계 시 설명변수에 교란요인 추가하면 된다**
- 회귀모델에 교란요인을 추가하여 구해진 처치변수에 대한 회귀계수는
- **교란요인이 고정된 상태에서의 처치변수가 변화했을 때 결과변수의 기댓값 변화량을 의미함**
- **즉, 처치와 결과 사이의 관계를 추정하는 동안 교란 요인을 고정하는 효과**

```python
import statsmodels.formula.api as smf
```

### 다중선형회귀의 또 다른 해석, FWL(프리슈-워-로벨) 정리 (교란효과 보정)
- **(1) 편향 제거 (debiasing) = T - E[T|X]**
    - 목적: 처치 중 교란 요인으로 설명 가능한 부분을 제외한 순수처치효과를 구하기 위함
    - 방법: 교란요인으로 처치 T를 예측하는 모델 적합 후 처치 잔차(=실제T-예측T) 구하기
    - 노트: 편향 제거만 해도 처치가 결과에 미치는 인과적 영향에 대해 편향되지 않은 추정값 얻을 수 있음 (다만 p값 큼)
- **(2) 잡음 제거 (denoising) = Y - E[Y|X]**
    - 목적: 결과 중 교란 요인으로 설명 가능한 부분을 제외한 순수결과효과를 구하기 위함
    - 방법: 교란 요인으로 결과 Y를 예측하는 모델 적합 후 결과 잔차(=실제Y-예측Y) 구하기
    - 노트: 해당 단계를 수행해도 인과추정값은 바뀌지 않지만 분산을 줄일 수 있음
- **(3) 인과효과 추정값 구하기**
    - 목적: 교란효과를 보정한 인과추정값을 구하기 위함
    - 방법: 처치 잔차로 결과 잔차를 예측하는 모델 적합하여 처치가 결과에 미치는 인과효과 추정값 구하기
- 잡다한 지식
    - FWL 뜻은 세 경제학자의 이름을 딴 것임

```python
model_debiased = smf.ols("credit_limit ~ credit_score1 + credit_score2 + wage", data=risk_data).fit()
model_denoised = smf.ols("default ~ credit_score1 + credit_score2 + wage", data=risk_data).fit()

risk_data = risk_data.assign(credit_limit_res = model_debiased.resid)
risk_data = risk_data.assign(default_res = model_denoised.resid)

model_debiased = smf.ols("default ~ credit_limit_res", data=risk_data).fit()
print(model_debiased.summary().tables[1])
"""
====================================================================================

credit_limit_res  3.063e-06   1.56e-06      1.957      0.050   -4.29e-09    6.13e-06
====================================================================================
"""

model_debiased_denoised = smf.ols("default_res ~ credit_limit_res", data=risk_data).fit()

"""

====================================================================================
"""
```

### 회귀분석 결과를 잠재적 결과 대체하는데 사용하기
- 방법 1) 회귀분석으로 E[Y0|X] 근사하여 잠재적 결과 Y0 대체하기
    - ATT = Average Treatment effect on the Treated (T=1)

$$
ATT = \frac{1}{N_{1}}\sum{I(T_{i}=1)(Y_{i}-\hat{\mu_{0}}(X_{i}))}
$$

- 방법 2) 회귀분석으로 E[Y1|X] 근사하여 잠재적 결과 Y1 대체하기
    - ATU = Average Treatment Effect on the Untreated (T=0)

$$
ATU = \frac{1}{N_{0}}\sum{I(T_{i}=0)(\hat{\mu_{1}}(X_{i})-Y_{i})}
$$

- 방법 3) 잠재적 결과 Y0, Y1 모두 대체하기
    - ATE = Average Treatment Effect

$$
ATE=\frac{1}{N}\sum_{i}{(\hat{\mu_{1}}(X_{i})-\hat{\mu_{0}}(X_{i}))}
$$

$$
ATE=\frac{1}{N}\sum_{i}{I(T_{i}=1)(Y_{i}-\hat{\mu_{0}}(X_{i}))+I(T_{i}=0)(\hat{\mu_{1}}(X_{i})-Y_{i})}
$$

### 회귀분석에서 양수성과 외삽
- 회귀분석은 잠재적 결과를 모수적으로 모델링하여 외삽(extrapolation) 가능
- 처치를 받은 집단과 받지 않은 집단간 공변량이 거의 겹치지 않는 경우 외삽 문제될 수 있음
- ⇒ 양수성 가정이 충족되지 않을 경우 회귀분석은 외삽을 통해 해당 가정이 충족되지 않는 영역 대체
    - 양수성 가정: 공변량 X=x에 대해 처치확률이 0 초과 1 미만인 상태 (0 < P(T=t|X) < 1)


## * 인사이트 및 학습 포인트
- (1) A/B 테스트 데이터에서 X로 처치, Y로 결과로 설정 후 회귀분석 시 처치에 대한 회귀계수가 ATE 추정량이 됨
- (2) 비실험 데이터에서 X로 처치 및 교란변수, Y로 결과 설정 후 회귀분석 시 처치에 대한 회귀계수가 ATE 추정량이 됨
    - 교란편향 보정 후 구한 추정치
- (3) FWL(프리슈-워-로벨) 정리를 사용하면 다중회귀분석으로 선택편향 보정하는 과정을 해석할 수 있다
    - (1) 편향제거(debiasing) → (2) 잡음제거(denoising) → (3) 결과 해석
        - (1) 편향제거: 처치변수 중 교란변수로 설명 가능한 부분 제거
        - (2) 잡읍제거: 결과변수 중 교란변수로 설명 가능한 부분 제거
        - (3) 결과해석: 교란변수를 통제한 뒤 처치가 결과에 미치는 영향 확인


## * 추가 질문 및 토론거리
- **책에서 신용한도(T) - 채무불이행여부(Y) 사이의 관계를 추정할 때 선형회귀 사용하는 이유? (by ChatGPT)**
    - (1) **해석 단순성**: 신용한도가 1만큼 늘었을 때 채무불이행확률이 평균적으로 (계수)만큼 증가한다고 직관적 해석 가능
    - (2) FWL 적용 불가: 로짓 함수는 비선형이라 FWL 정리 적용 안 됨
    - (3) 인과추론 목적: 인과추론에서는 목적이 예측이 아니라 평균적 인과효과를 구하는 것이기 때문
